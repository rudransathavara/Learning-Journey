# Waterfall Charts in Microsoft Excel

## 1. What Is a Waterfall Chart?

A **waterfall chart** shows how an initial value changes as positive and negative values are added or subtracted.

It is useful for understanding how a starting amount, such as net income, is affected by a series of income and expenses.

For example, a company can use a waterfall chart to visualize its second-quarter income and expenses.

### Key Features

- **Positive values:** Show increases in the running total.
- **Negative values:** Show decreases in the running total.
- **Color coding:** Helps distinguish positive and negative values.
- **Running total:** Shows how each value affects the overall result.

Waterfall charts are commonly used to analyze income, expenses, profits, and financial performance.

## 3. Insert a Waterfall Chart

Follow these steps:

1. Select **A3:B13**.
2. Go to the **Insert** tab.
3. Find the **Charts** group.
4. Open the chart options that contain Waterfall, Funnel, Stock, Surface, and Radar charts.
5. Select **Waterfall**, which is the first option in this chart group.

Excel will create a waterfall chart on your worksheet.

**Tip:** Make the chart larger if necessary. Waterfall charts can contain several data points, so additional space can improve readability.

## 4. Understand Positive and Negative Values

A waterfall chart uses different colors to distinguish increases from decreases.

- Positive values increase the running total.
- Negative values decrease the running total.

However, the chart may initially treat certain values as changes when they should represent fixed totals or reference points.

In the practice example, some negative values need to be adjusted to improve the chart's presentation.

## 5. Set a Data Point as a Total

Excel allows you to mark individual data points as totals.

This is useful when a value represents a subtotal, a final balance, or another important reference point rather than an ordinary increase or decrease.

### Steps

1. Click the waterfall chart.
2. Click the data point you want to adjust.
3. Click that same data point again to select only that individual point rather than the entire data series.
4. Right-click the selected data point.
5. Choose **Set as Total**.
6. Repeat for any other data points that should be displayed as totals.

In the practice example, the instructor applies this option to two negative data points.

### Why Is This Important?

Setting a point as a total tells Excel to display it as a standalone total rather than as a change from the previous point.

This can make the chart more accurately represent the intended financial information.

**Important:** Use Set as Total only for values that genuinely represent totals or fixed reference points. An ordinary expense should normally remain a negative change.

## 6. Review the Finished Chart

After adjusting the relevant data points:

1. Click outside the chart to deselect it.
2. Review the colors and positions of the bars.
3. Check that positive and negative changes are easy to distinguish.
4. Confirm that any totals appear correctly.

Your chart should now provide a clearer view of how the different values affect the overall financial result.

## 7. Key Takeaways

- Waterfall charts visualize how positive and negative values affect an initial amount.
- They are useful for analyzing income, expenses, and changes in financial balances.
- Different colors help distinguish increases from decreases.
- Select **Insert > Charts > Waterfall** to create the chart.
- Use **Set as Total** to display a selected data point as a standalone total.
- Click a data point twice to select an individual point for formatting.
- Use Set as Total carefully, making sure the selected point represents a genuine total or reference value.
