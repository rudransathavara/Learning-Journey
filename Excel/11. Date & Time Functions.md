# Date and Time Functions in Excel

## What Are Date and Time Functions?

Excel has several functions that help you work with dates and times.

These are particularly useful when recording financial information, creating expense reports, and tracking when information was entered.

In this lesson, we will cover:
- `TODAY()` — returns the current date.
- `NOW()` — returns the current date and time.
- Keyboard shortcuts for inserting dates and times that do not automatically update.

## 1. The TODAY Function

The TODAY function returns the current date from your computer.

### Formula

`=TODAY()`

### How to Use It

1. Click the cell where you want the date to appear.
2. Type `=TODAY()`.
3. Press Enter.

Excel will display the current date.

### Important Note

The date returned by `TODAY()` updates when Excel recalculates the formula. This means the date can change when you reopen the workbook or when the worksheet recalculates.

Use this function when you want the current date to update automatically.

## 2. The NOW Function

The NOW function returns the current date and time from your computer.

### Formula

`=NOW()`

### How to Use It

1. Click the cell where you want the date and time to appear.
2. Type `=NOW()`.
3. Press Enter.

Excel will display the current date and time.

### Formatting the Date and Time

Excel may display the time using a 24-hour clock.

To change how it appears:

1. Select the cell containing the formula.
2. Go to the **Home** tab.
3. Find the **Number** group.
4. Open the number format options and select **More Number Formats**.
5. Choose a suitable date or time format.

You can select a format that displays the time using a 12-hour clock.

### Important Note

The date and time returned by `NOW()` update when Excel recalculates the formula.

## 3. Inserting a Date That Does Not Update

Sometimes you want to record a date that stays the same, rather than automatically changing.

Excel provides a keyboard shortcut for inserting the current date as a fixed value.

### Keyboard Shortcut (Windows)

**Ctrl + ;**

### How to Use It

1. Select the cell where you want the date.
2. Press **Ctrl + ;**.
3. Excel inserts the current date into the cell.

Unlike `=TODAY()`, the inserted date is a fixed value and will not automatically update when you reopen the workbook.

## 4. Inserting a Time That Does Not Update

You can also insert the current time as a fixed value using a keyboard shortcut.

### Keyboard Shortcut (Windows)

**Ctrl + Shift + ;**

### How to Use It

1. Select the cell where you want the time.
2. Press **Ctrl + Shift + ;**.
3. Excel inserts the current time into the cell.

The inserted time will not automatically update.

### Inserting Both Date and Time

You can enter a fixed date and time into the same cell:

1. Press **Ctrl + ;** to insert the current date.
2. Press the **Spacebar** to add a space.
3. Press **Ctrl + Shift + ;** to insert the current time.

The date and time will remain fixed rather than updating automatically.

## 5. TODAY and NOW vs Keyboard Shortcuts

| Method | What It Inserts | Automatically Updates? |
|---|---|---|
| `=TODAY()` | Current date | Yes, when Excel recalculates |
| `=NOW()` | Current date and time | Yes, when Excel recalculates |
| `Ctrl + ;` | Current date | No |
| `Ctrl + Shift + ;` | Current time | No |

## Key Takeaways

- `TODAY()` returns the current date.
- `NOW()` returns the current date and time.
- Both functions can update when Excel recalculates.
- `Ctrl + ;` inserts a fixed date.
- `Ctrl + Shift + ;` inserts a fixed time.
- You can change date and time formats using the Number group on the Home tab.
- Fixed dates and times are useful when recording financial information that should not change later.
