# Data Validation in Excel

## What Is Data Validation?

Data Validation is a feature in Excel that controls what information users can enter into specific cells.

It helps ensure that the data entered into a spreadsheet follows certain rules.

For example, you can use Data Validation to make sure that income amounts entered into a spreadsheet are at least £15,000.

## 1. Setting Up Data Validation

Let's say column H contains income amounts, and you want to make sure that no income below 15,000 can be entered.

### How to Set It Up

1. Select the cells where you want to apply Data Validation, excluding the column heading.
2. Go to the **Data** tab.
3. Find **Data Validation** in the Data Tools group.
4. Click Data Validation to open the settings window.
5. Under the **Settings** tab, change Allow from Any Value to **Whole Number**.
6. Set the criteria to **greater than or equal to**.
7. Enter `15000` as the minimum value.
8. Click OK to apply the rule.

Now, users must enter whole numbers that are 15,000 or greater into those cells.

**Note:** You do not need to enter currency symbols or decimal places when setting this rule. These relate to how the values are formatted, rather than the validation criteria.

## 2. Input Messages

An input message provides instructions to users when they select a cell that has Data Validation applied.

This helps users understand what information they need to enter.

### How to Set Up an Input Message

1. Open the Data Validation window.
2. Select the **Input Message** tab.
3. Enter a title, such as `Income Amount`.
4. Enter a message explaining what the user should enter.

For example:

**Title:** Income Amount

**Message:** You must enter an income amount of 15,000 or higher.

When a user selects one of the validated cells, the message will appear.

## 3. Error Alerts

An error alert appears when a user tries to enter information that does not meet the validation rules.

Excel provides three error alert styles:

- **Stop:** Prevents the user from accepting an invalid entry.
- **Warning:** Warns the user about an invalid entry but can allow them to continue.
- **Information:** Informs the user about an invalid entry but can allow them to continue.

If you want to prevent incorrect values from being entered, use the **Stop** style.

### How to Set Up an Error Alert

1. Open the Data Validation window.
2. Select the **Error Alert** tab.
3. Make sure **Show error alert after invalid data is entered** is enabled.
4. Select **Stop** as the error style.
5. Enter a title, such as `Incorrect Income Amount`.
6. Enter an error message explaining the rule.

For example:

**Title:** Incorrect Income Amount

**Message:** You have entered an incorrect income amount. It must be 15,000 or higher.

7. Click OK to apply the settings.

### Testing the Validation

When a user enters an invalid value and presses Enter, Excel displays the error alert.

The user can retry the entry or cancel it. With the Stop alert, Excel will not accept the invalid value.

## 4. Applying Data Validation to Existing Cells

Data Validation can be applied to both blank cells and cells that already contain data.

However, applying a validation rule does not automatically remove or correct existing values that break the rule.

The rule applies when a user enters or changes a value in a validated cell.

## 5. Removing Data Validation

If you no longer need a validation rule, you can remove it.

### How to Remove Data Validation

1. Select the cells containing the validation rule.
2. Go to the **Data** tab.
3. Click **Data Validation**.
4. Click **Clear All** in the Data Validation window.
5. Click OK.

This removes the validation rules, input messages, and error alerts associated with those cells.

## Key Takeaways

- Data Validation controls what information can be entered into cells.
- You can set rules such as allowing only whole numbers greater than or equal to 15,000.
- Input Messages explain what users should enter.
- Error Alerts warn users when their entries do not meet the rules.
- The Stop error alert prevents invalid entries from being accepted.
- Data Validation does not automatically correct existing invalid values.
- You can remove validation rules using the Clear All button.
