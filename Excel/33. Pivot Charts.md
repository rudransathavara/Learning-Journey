# Pivot Charts in Microsoft Excel

## 1. What Is a Pivot Chart?

A **PivotChart** is a chart connected to a PivotTable-style data analysis structure.

It allows you to visualize selected fields from a large dataset without having to chart every column in the original data.

PivotCharts are useful when:
- The source dataset contains many columns.
- You want to compare selected categories.
- You want to change the fields displayed in a chart.
- You need a chart that can be reorganized through field selections.

For example, you could create a chart showing tickets sold by destination and then break the results down by office.

## 2. Why Use a Pivot Chart?

When you try to create a standard chart directly from a wide dataset, Excel may include too many fields or produce a chart that is difficult to interpret.

A PivotChart lets you choose the information you want to display.

Instead of charting the entire dataset, you can select specific fields and summarize them first.

## 3. Prepare the Source Data

For this lesson, use the practice file called `Create Pivot Chart`.

Before creating a PivotChart, make sure the source data has:

- Clear column headings.
- One record per row.
- No entirely blank rows inside the dataset.

These requirements help Excel identify the source range correctly.

## 4. Create a Pivot Chart

### Steps

1. Open the practice file.
2. Click any cell inside the source data.
3. Go to the **Insert** tab.
4. Find the **PivotChart** button in the Charts group.
5. Open the PivotChart options.
6. Choose to create a PivotChart.
7. Confirm the source data range.
8. Choose **New Worksheet** for the chart location.
9. Click **OK**.

Excel creates a new worksheet containing a PivotChart and the PivotChart Field List.

Depending on the option selected, Excel may also create an associated PivotTable.

## 5. Understand the PivotChart Field List

The PivotChart Field List contains the column headings from your source dataset.

You can drag fields into different areas to control what appears in the chart.

| Area | Purpose |
|---|---|
| Filters | Filters the data used by the chart. |
| Legend (Series) | Separates data into series, often shown with different colors. |
| Axis (Categories) | Determines the categories displayed along the chart axis. |
| Values | Determines the numeric values summarized in the chart. |

The exact arrangement may vary slightly depending on the Excel version and chart type.

## 6. Build a Pivot Chart

Suppose you want to display tickets sold by destination.

### Step 1: Add Destination to the Axis

Drag **Destination** into the Axis (Categories) area.

The chart now uses destinations as its categories.

### Step 2: Add Tickets Sold to Values

Drag **Tickets Sold** into the Values area.

Excel summarizes the ticket values and displays them in the chart.

The chart now shows the selected measure by destination.

### Step 3: Add Office to the Legend

Drag **Office** into the Legend (Series) area.

Excel divides the chart into series based on the office field.

The chart updates automatically to reflect the additional information.

## 7. Change the Chart's Fields

You can change the chart's layout by moving fields between the areas.

For example:

1. Move Office from Legend (Series) to Axis (Categories).
2. Remove Destination from Axis (Categories), if it is no longer needed.
3. Review the updated chart.

The chart changes to reflect the new arrangement.

The associated PivotTable-style analysis also updates when you change the fields in the connected PivotChart.

**Tip:** Use a small number of relevant fields to keep the chart easy to interpret.

## 8. Format a Pivot Chart

PivotCharts offer formatting options similar to those available for standard charts.

### A. Chart Elements

Select the chart and use the Chart Elements button, commonly represented by a green plus sign.

Depending on the chart and Excel version, you can add elements such as:
- Data labels.
- Axis titles.
- A chart title.
- A data table.

### B. Chart Styles

Use the Chart Styles button, commonly represented by a paintbrush, to change the chart's appearance.

You can choose a different style without changing the underlying chart type.

### C. Chart Colors

The chart style options also allow you to choose different color palettes.

Select colors that distinguish the series clearly and keep the chart readable.

## 9. Refresh a Pivot Chart

A PivotChart is connected to its underlying PivotTable-style data structure.

If the source data changes, the chart may need to be refreshed.

### Steps

1. Right-click the PivotChart or its associated PivotTable.
2. Select **Refresh**.

Excel refreshes the connected analysis and updates the chart.

If new records are added outside the original source range, you may also need to expand or change the source data range.

## 10. Key Takeaways

- PivotCharts visualize selected fields from a large dataset.
- They are useful when a standard chart would include too much information.
- Create one using **Insert > PivotChart**.
- Use Axis (Categories) to define the chart categories.
- Use Values to choose the numeric measure.
- Use Legend (Series) to compare different groups.
- Rearranging fields changes the chart.
- Use Chart Elements and Chart Styles to improve readability.
- Refresh the PivotChart when the underlying data changes.
