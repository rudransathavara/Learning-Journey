# PPMT Function in Excel

## 1. What Is the PPMT Function?

The **PPMT (Principal Payment)** function calculates the portion of a loan payment that goes toward repaying the principal for a specific payment period.

When you make a loan payment, the payment is generally divided into two parts:

- **Principal:** The amount that reduces the original loan balance.
- **Interest:** The cost of borrowing the money.

The PPMT function helps you identify how much of each payment goes toward reducing the loan balance.

It assumes a constant interest rate and a regular payment schedule.

## 2. PPMT Function Syntax

```excel
=PPMT(rate, per, nper, pv, [fv], [type])
```

### Arguments

| Argument | Description | Required? |
|---|---|---|
| `rate` | The interest rate for each payment period. | Yes |
| `per` | The specific payment period for which you want to calculate the principal portion. | Yes |
| `nper` | The total number of payment periods over the loan's duration. | Yes |
| `pv` | The present value, or the original amount borrowed. | Yes |
| `fv` | The desired balance after the final payment. Usually `0` for a fully repaid loan. | No |
| `type` | Specifies when payments are due: `0` or omitted means at the end of each period; `1` means at the beginning. | No |

The first four arguments are required.

## 3. Understanding the Loan Information

In the practice file, the following cells contain the loan information:

| Cell | Description | Example |
|---|---|---|
| `B1` | Annual interest rate | 8% |
| `B2` | Loan term in years | Depends on the practice file |
| `B3` | Number of payments per year | 12 |
| `B4` | Original loan amount | Depends on the practice file |
| `A7` | Payment period number | 1 |

These example descriptions follow the worksheet layout used in the lesson. Use the actual values in your practice file.

Because payments are made monthly, the annual interest rate and loan term must be converted into monthly values.

### Convert the Annual Interest Rate

Divide the annual interest rate by the number of payments per year:

```excel
=B1/B3
```

For an annual interest rate of 8% and 12 payments per year:

`8% / 12 = approximately 0.6667% per month`

### Calculate the Total Number of Payments

Multiply the loan term in years by the number of payments per year:

```excel
=B2*B3
```

For example, a two-year loan with monthly payments has:

`2 × 12 = 24 payments`

## 4. Calculating the Principal Payment with PPMT

In the practice file, the PPMT formula is entered in cell `C7`.

### Step 1: Select the Cell

Click cell `C7`, where you want to calculate the principal portion of the loan payment.

### Step 2: Enter the Formula

Using the cell references from the practice file, enter:

```excel
=PPMT(B1/B3, A7, B2*B3, B4)
```

This formula calculates the principal portion of the payment for the period specified in cell `A7`.

The formula uses:

- `B1/B3` — the monthly interest rate.
- `A7` — the payment period being calculated.
- `B2*B3` — the total number of monthly payments.
- `B4` — the original amount borrowed.

### Step 3: Press Enter

Excel calculates the principal portion of the payment for the specified period.

The result may be negative because it represents money being paid out to repay the loan.

## 5. Making Cell References Absolute

To calculate the principal portion for multiple payment periods, you need to copy the formula down the column.

However, some cell references must remain fixed, while the payment period reference must change.

The corrected formula is:

```excel
=PPMT($B$1/$B$3, A7, $B$2*$B$3, $B$4)
```

### Which References Should Be Fixed?

| Reference | Purpose | Reference Type |
|---|---|---|
| `$B$1` | Annual interest rate | Absolute |
| `$B$3` | Payments per year | Absolute |
| `A7` | Current payment period | Relative |
| `$B$2` | Loan term in years | Absolute |
| `$B$4` | Original loan amount | Absolute |

The dollar signs (`$`) lock both the column and row of a cell reference.

The reference `A7` remains relative so that it changes to `A8`, `A9`, `A10`, and so on when the formula is copied down.

### Using the F4 Key

In Excel for Windows:

1. Select the cell containing the formula.
2. Click the formula bar.
3. Select a cell reference that needs to remain fixed.
4. Press **F4** to toggle through the reference types.
5. Repeat for the other references that need to be fixed.
6. Press Enter to confirm the formula.

On some laptops, you may need to press `Fn + F4`. Keyboard shortcuts can vary by platform.

## 6. Filling the Formula Down the Loan Schedule

Once the formula contains the correct absolute and relative references:

1. Select cell `C7`.
2. Move your pointer to the small square in the bottom-right corner of the cell, called the **fill handle**.
3. When the pointer changes to a black cross, click and drag down the column.
4. Excel copies the formula into the selected cells.

As the formula moves down, the payment period changes, but the loan information stays fixed.

For example:

**First payment period:**

```excel
=PPMT($B$1/$B$3, A7, $B$2*$B$3, $B$4)
```

**Second payment period:**

```excel
=PPMT($B$1/$B$3, A8, $B$2*$B$3, $B$4)
```

**Third payment period:**

```excel
=PPMT($B$1/$B$3, A9, $B$2*$B$3, $B$4)
```

The principal amount changes from one period to the next because the interest and principal portions of each payment change as the loan is repaid.

## 7. How PPMT Fits into a Loan Schedule

A loan schedule often separates each payment into principal and interest.

| Function | Purpose |
|---|---|
| `PMT` | Calculates the total regular loan payment. |
| `PPMT` | Calculates the principal portion of a payment for a specific period. |
| `IPMT` | Calculates the interest portion of a payment for a specific period. |

For a standard loan with equal payments and a fixed interest rate:

**Total payment = Principal portion + Interest portion**

The PPMT and IPMT functions can help you understand how much of each payment reduces the loan balance and how much goes toward interest.

## 8. Important Things to Remember

- **PPMT calculates principal only.** It does not return the full loan payment.
- **The `per` argument identifies the payment period.** For example, `1` represents the first payment period, and `12` represents the twelfth.
- **Use the correct interest rate for each period.** For monthly payments, divide the annual interest rate by 12 when the rate is quoted annually.
- **Calculate the total number of payments correctly.** Multiply the loan term by the number of payments per year.
- **Use absolute references for fixed loan information.** This allows you to copy the formula down without changing the inputs.
- **Keep the payment period reference relative.** This lets Excel calculate a different principal amount for each period.
- **Negative results are normal.** They represent payments made toward the loan.
- **The principal portion generally changes over time.** For a standard fixed-rate loan with equal payments, the principal portion typically increases as the loan is repaid.

## 9. Summary

The PPMT function calculates the principal portion of a loan payment for a specific period.

Using the worksheet cells from the lesson, the formula is:

```excel
=PPMT($B$1/$B$3, A7, $B$2*$B$3, $B$4)
```

The formula fixes the loan information using absolute references while allowing the payment period to change as you copy it down the schedule.

**In summary:** PPMT is useful for breaking loan payments into their principal component, helping you understand how the amount borrowed decreases over time.
