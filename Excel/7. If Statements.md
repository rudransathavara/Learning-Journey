# IF Statements in Excel

## What is an IF Statement?
An IF statement checks whether a condition is true or false and returns a result depending on the answer.

For example, you can use an IF statement to check whether a student's score is a pass or a fail.

## 1. The IF Formula
The basic structure of an IF formula is:

`=IF(logical_test, value_if_true, value_if_false)`

- **logical_test:** The condition you want Excel to check.
- **value_if_true:** What Excel should display if the condition is true.
- **value_if_false:** What Excel should display if the condition is false.

## 2. Example of an IF Statement

Imagine cell A2 contains a student's score.

`=IF(A2>=50, "Pass", "Fail")`

This formula checks whether the score in A2 is 50 or higher.

- If the score is 50 or higher, Excel displays **Pass**.
- If the score is below 50, Excel displays **Fail**.

## 3. Comparison Operators

IF statements use comparison operators to check conditions.

| Operator | Meaning | Example |
|---|---|---|
| `=` | Equal to | `A2=50` |
| `>` | Greater than | `A2>50` |
| `<` | Less than | `A2<50` |
| `>=` | Greater than or equal to | `A2>=50` |
| `<=` | Less than or equal to | `A2<=50` |
| `<>` | Not equal to | `A2<>50` |

## 4. How to Use an IF Statement

1. Click the cell where you want the result to appear.
2. Type your IF formula, starting with `=IF`.
3. Enter the condition you want Excel to check.
4. Enter the result for when the condition is true.
5. Enter the result for when the condition is false.
6. Press Enter to calculate the result.

## Key Takeaways

- IF statements check whether a condition is true or false.
- They return one result if the condition is true and another if it is false.
- The formula starts with `=IF`.
- IF statements are useful for making decisions automatically in Excel.
