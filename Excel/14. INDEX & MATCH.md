# INDEX and MATCH in Excel

## What Are INDEX and MATCH?

INDEX and MATCH are two Excel functions that can be combined to look up information in a table.

They are often used as an alternative to VLOOKUP because they allow you to look up a value without needing the lookup column to be on the left of the column containing the result.

- **INDEX:** Returns a value from a specific position within a range.
- **MATCH:** Finds the position of a particular value within a range.

When combined, these functions can find a value and return related information from another column.

## 1. The INDEX Function

The INDEX function returns the value located at a specific row and column within a selected range.

### Formula Structure

`=INDEX(array, row_num, column_num)`

The formula has three arguments:

- **array:** The range of cells containing the information.
- **row_num:** The row position of the value you want to return within the selected range.
- **column_num:** The column position of the value you want to return within the selected range.

### Example

Imagine you have a table in cells A4:G58 and want to return the value located at the fifth row and seventh column of that selected range.

Use:

`=INDEX(A4:G58, 5, 7)`

This formula:
1. Looks at the range A4:G58.
2. Moves to the fifth row within that range.
3. Moves to the seventh column within that range.
4. Returns the value found at that position.

**Important:** The row and column numbers refer to positions within the selected range, not the worksheet's row numbers or column letters.

## 2. The MATCH Function

The MATCH function finds the position of a specific value within a range.

Unlike INDEX, MATCH does not return the value itself. It returns the position where the value is found.

### Formula Structure

`=MATCH(lookup_value, lookup_array, match_type)`

The formula has three arguments:

- **lookup_value:** The value you want to find.
- **lookup_array:** The range of cells Excel searches.
- **match_type:** Determines how Excel looks for a match.

### Understanding Match Types

| Match Type | Meaning |
|---|---|
| `0` | Finds an exact match. |
| `1` | Finds the largest value less than or equal to the lookup value. The list must be sorted in ascending order. |
| `-1` | Finds the smallest value greater than or equal to the lookup value. The list must be sorted in descending order. |

### Example

Imagine cells B2:B5 contain a list of product numbers, and you want to find the position of the number 25.

Use:

`=MATCH(25, B2:B5, 0)`

This formula searches for 25 and returns its position within the range.

If 25 is the first item in the range, the result will be `1`.

**Important:** MATCH returns the position within the selected range, not the worksheet row number.

## 3. Combining INDEX and MATCH

When you combine INDEX and MATCH, you can find a value in one column and return related information from another column.

### Formula Structure

`=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))`

- **return_range:** The range containing the information you want returned.
- **lookup_value:** The value you want to find.
- **lookup_range:** The range Excel searches for the lookup value.
- **0:** Tells MATCH to find an exact match.

MATCH finds the position of the lookup value, and INDEX uses that position to return the corresponding value.

### Example: Finding a Customer Total by City

Imagine your table is in cells A1:D11:

- Column B contains city names.
- Column D contains customer totals.

You want to find the customer total for Phoenix.

Use:

`=INDEX(D1:D11, MATCH("Phoenix", B1:B11, 0))`

This formula:
1. MATCH searches B1:B11 for Phoenix.
2. MATCH returns the position where Phoenix is found.
3. INDEX uses that position in D1:D11.
4. Excel returns the customer total for Phoenix.

You can replace `"Phoenix"` with another city to look up a different customer total.

## 4. INDEX and MATCH vs VLOOKUP

| Feature | VLOOKUP | INDEX and MATCH |
|---|---|---|
| Looks up information | Yes | Yes |
| Returns a related value | Yes | Yes |
| Lookup column must be on the left of the return column | Yes | No |
| Requires a column index number | Yes | No |
| Can use an exact match | Yes, with `FALSE` | Yes, with `0` in MATCH |

## Key Takeaways

- INDEX returns a value from a specific position in a range.
- MATCH finds the position of a value within a range.
- MATCH returns a position, not the matching value itself.
- Combining INDEX and MATCH allows you to find information using a lookup column that is not necessarily on the left.
- Use `0` in MATCH when you need an exact match.
- INDEX and MATCH provide a flexible alternative to VLOOKUP.
