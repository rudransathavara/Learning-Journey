# Regression Analysis in Microsoft Excel

## 1. What Is Regression Analysis?

**Regression analysis** is a statistical method used to estimate the relationship between a dependent variable and one or more independent variables.

It helps you understand how variables are related and can be used to model or predict outcomes.

For example, you might examine the relationship between:
- The number of flu cases.
- The number of flu vaccinations administered.

Regression analysis can estimate how changes in one variable are associated with changes in another.

**Important:** A relationship between two variables does not, by itself, prove that one causes the other.

## 2. Understand the Variables

Regression analysis uses two main types of variables.

### Dependent Variable (Y)

The dependent variable is the outcome you want to explain or predict.

In the lesson's example, this is the number of flu vaccines.

### Independent Variable (X)

The independent variable is the factor used to explain or predict the dependent variable.

In the example, this is the number of flu cases.

The regression model estimates how the dependent variable relates to the independent variable.

## 3. Enable the Analysis ToolPak

Excel's Regression tool is available through the **Analysis ToolPak** add-in in supported desktop versions.

For this lesson, use the practice file called `Regression Analysis`.

### Steps in Excel for Windows

1. Open Excel.
2. Go to **File**.
3. Select **Options**.
4. Choose **Add-ins**.
5. At the bottom, find the **Manage** drop-down.
6. Select **Excel Add-ins**, if necessary.
7. Click **Go**.
8. Check **Analysis ToolPak**.
9. Click **OK**.

The Analysis ToolPak should now be available.

**Note:** The exact steps differ across Excel versions and operating systems. If you are using Excel for Mac or Excel for the web, check the available analysis features for your version.

## 4. Open the Regression Tool

Once the Analysis ToolPak is enabled:

1. Go to the **Data** tab.
2. Find the **Data Analysis** command.
3. Click it.
4. Select **Regression**.
5. Click **OK**.

The Regression dialog box opens.

## 5. Configure the Regression Analysis

The example uses flu cases and flu vaccination data.

### Step 1: Enter the Input Y Range

The Y range contains the dependent variable.

For this example, the flu vaccine values are in **C3:C15**.

Enter:

`$C$3:$C$15`

### Step 2: Enter the Input X Range

The X range contains the independent variable.

Select the cells containing the flu case data.

Use the appropriate range from your practice file.

### Step 3: Set the Labels Option

Check **Labels** if the selected input ranges include column headings.

If the ranges contain only numeric data and no headings, leave this option unchecked.

### Step 4: Choose the Output Range

The output range determines where Excel places the regression report.

For the lesson, select cell **A18**.

### Step 5: Run the Analysis

Review your settings and click **OK**.

Excel generates a regression report in the selected output area.

## 6. Understand the Regression Output

The report contains several statistical measures. The most useful starting points include Multiple R, R Square, Adjusted R Square, and Significance F.

### A. Multiple R

Multiple R is the correlation-related measure reported by Excel's regression output.

In simple linear regression, it corresponds to the magnitude of the correlation between the observed and fitted values.

A value closer to 1 indicates a stronger linear association in magnitude, but the sign of the relationship is not shown by Multiple R alone.

To understand whether the relationship is positive or negative, examine the regression coefficient for the independent variable.

### B. R Square

R Square is also called the **coefficient of determination**.

It measures the proportion of variation in the dependent variable explained by the fitted regression model.

For example, an R Square of 0.96 means the model explains approximately 96% of the observed variation in the dependent variable in the analyzed data.

A high R Square does not necessarily mean that the model is appropriate or that its predictions will be accurate for new data.

### C. Adjusted R Square

Adjusted R Square modifies R Square to account for the number of independent variables and the sample size.

It can be useful when comparing models with different numbers of predictors.

### D. ANOVA

ANOVA stands for **Analysis of Variance**.

In the regression report, the ANOVA section summarizes variation associated with the regression model and the residual errors.

Common headings include:

| Heading | Meaning |
|---|---|
| DF | Degrees of freedom |
| SS | Sum of squares |
| MS | Mean square |
| F | F-statistic used to test the overall regression model |
| Significance F | P-value associated with the overall F-test |

A small Significance F can provide evidence that the model explains variation beyond what would be expected under the overall null hypothesis.

Interpret it alongside the model assumptions and the rest of the regression output.

## 7. Create a Scatter Chart

A scatter chart can help visualize the relationship between two numeric variables.

### Steps

1. Return to the source data.
2. Select the relevant data range, including the two numeric variables.
3. Go to the **Insert** tab.
4. Find the **Scatter (X, Y)** chart options.
5. Select the basic scatter chart.

Each point represents an observation, with one variable plotted on the horizontal axis and the other on the vertical axis.

A scatter chart helps you see whether the relationship appears positive, negative, nonlinear, or weak.

**Tip:** Make sure the correct variable is assigned to each axis. A scatter chart uses numeric X and Y values.

## 8. Add a Trendline

A trendline can help summarize the pattern shown in a scatter chart.

### Steps

1. Select the chart.
2. Open **Chart Design** or the chart's Chart Elements options.
3. Add a **Trendline**, if available.
4. Choose the appropriate data series.
5. Review the fitted line.

You can use the chart's formatting options to change the trendline's appearance.

A linear trendline can make an overall positive or negative pattern easier to see, but it does not replace a full regression analysis.

## 9. Key Takeaways

- Regression analysis estimates relationships between variables.
- The dependent variable is represented by Y.
- Independent variables are represented by X.
- The Analysis ToolPak provides the Regression tool in supported desktop Excel versions.
- Use **Data > Data Analysis > Regression** to run the analysis.
- Multiple R describes the magnitude of the correlation-related measure in the regression output.
- R Square measures the proportion of variation explained by the model.
- Adjusted R Square accounts for model complexity and sample size.
- ANOVA summarizes variation and includes the overall F-test.
- Scatter charts and trendlines help visualize relationships.
