# SUMIF and AVERAGEIF Functions in Excel

## What are SUMIF and AVERAGEIF?

**SUMIF** and **AVERAGEIF** are functions that allow you to calculate values based on a specific condition, also known as a criteria.

- **SUMIF:** Adds values that meet a specific condition.
- **AVERAGEIF:** Calculates the average of values that meet a specific condition.

For example, you can use SUMIF to calculate the total sales for a particular destination or AVERAGEIF to calculate the average sales for that destination.

## 1. The SUMIF Function

The SUMIF function adds together values that match a condition.

### Formula Structure

`=SUMIF(range, criteria, sum_range)`

The formula has three arguments:

- **range:** The cells Excel checks to find a match for your condition.
- **criteria:** The condition that Excel must match.
- **sum_range:** The cells containing the numbers you want to add.

### Example

Imagine column E contains destinations and column H contains sales totals.

To add all the values in column H where the destination in column E is Cancun, use:

`=SUMIF(E2:E200, "Cancun", H2:H200)`

This formula:
1. Checks cells E2 to E200 for the destination Cancun.
2. Finds the rows that match the condition.
3. Adds the corresponding values from H2 to H200.

**Important:** Text criteria, such as `"Cancun"`, must be placed inside quotation marks.

## 2. The AVERAGEIF Function

The AVERAGEIF function calculates the average of values that match a condition.

### Formula Structure

`=AVERAGEIF(range, criteria, average_range)`

The formula has three arguments:

- **range:** The cells Excel checks to find a match for your condition.
- **criteria:** The condition that Excel must match.
- **average_range:** The cells containing the numbers you want to average.

### Example

Using the same spreadsheet, imagine column E contains destinations and column H contains sales totals.

To calculate the average sales for Boston, use:

`=AVERAGEIF(E2:E200, "Boston", H2:H200)`

This formula:
1. Checks cells E2 to E200 for the destination Boston.
2. Finds the rows that match the condition.
3. Calculates the average of the corresponding values in H2 to H200.

You can format the result as currency if you want to display it as a monetary value.

## 3. Using the Insert Function Box

If you are new to these functions, you can use Excel's Insert Function box to help build the formula.

1. Select the cell where you want the result.
2. Click the **fx** button beside the formula bar.
3. Search for `SUMIF` or `AVERAGEIF`.
4. Select the correct function.
5. Enter the required arguments: range, criteria, and sum or average range.
6. Check the formula result.
7. Click **OK**.

**Note:** Make sure you select `SUMIF`, not `SUMIFS`, when following the SUMIF example.

## 4. Key Differences

| Function | Purpose | Example |
|---|---|---|
| `SUMIF` | Adds values that match a condition | `=SUMIF(E2:E200, "Cancun", H2:H200)` |
| `AVERAGEIF` | Averages values that match a condition | `=AVERAGEIF(E2:E200, "Boston", H2:H200)` |

## Key Takeaways

- SUMIF adds values based on a condition.
- AVERAGEIF calculates an average based on a condition.
- Both functions use a range and a criteria.
- SUMIF uses a `sum_range`, while AVERAGEIF uses an `average_range`.
- Text criteria must be enclosed in quotation marks.
- The Insert Function box can help you enter the correct arguments.
