# Loan Schedule with the PMT Function

## 1. What Is the PMT Function?

The **PMT function** in Excel calculates the regular payment required to repay a loan over a specified period, assuming a constant interest rate and equal payments.

It is commonly used to calculate monthly loan repayments.

For example, if you borrow money for two years and make monthly payments, the PMT function can calculate the fixed amount you need to pay each month.

A loan amortization schedule uses this payment amount to show the payments across the duration of the loan.

## 2. PMT Function Syntax

```excel
=PMT(rate, nper, pv, [fv], [type])
```

### Arguments

| Argument | Description | Required? |
|---|---|---|
| `rate` | The interest rate for each payment period. | Yes |
| `nper` | The total number of payment periods over the loan's duration. | Yes |
| `pv` | The present value, or the amount borrowed. | Yes |
| `fv` | The desired future balance after the final payment. Usually `0` for a fully repaid loan. | No |
| `type` | Specifies when payments are due: `0` or omitted means at the end of each period; `1` means at the beginning. | No |

For a basic loan payment calculation, you only need the first three arguments: `rate`, `nper`, and `pv`.

## 3. Understanding Monthly Loan Payments

When calculating monthly loan payments, you need to convert the annual interest rate and loan term into monthly values.

For example, suppose the worksheet contains the following information:

| Cell | Description | Example |
|---|---|---|
| `B3` | Annual interest rate | 6% |
| `B4` | Loan term in years | 2 |
| `B5` | Payments per year | 12 |
| `B6` | Amount borrowed | $20,000 |

These values are examples. Use the actual values in your practice file when following the lesson.

### Why Do We Divide the Interest Rate by 12?

If the interest rate is annual but payments are monthly, divide the annual rate by the number of payments per year.

```excel
=B3/B5
```

This converts the annual interest rate into a monthly interest rate.

### Why Do We Multiply the Loan Term by 12?

If the loan lasts two years and you make 12 payments per year, the total number of payments is:

```excel
=B4*B5
```

For a two-year loan with monthly payments:

`2 × 12 = 24 payments`

The interest rate and number of payment periods must use the same payment frequency.

## 4. Calculating the Monthly Payment with PMT

In the practice file, the monthly payment is calculated in cell `B9`.

### Step 1: Select the Cell

Click cell `B9`, where the PMT formula will be entered.

### Step 2: Enter the Formula

Use the following formula:

```excel
=PMT(B3/B5, B4*B5, B6)
```

This formula calculates the monthly loan payment using the information in cells `B3` through `B6`.

### Step 3: Press Enter

Excel calculates the payment required for each month of the loan.

The formula works as follows:

- `B3/B5` calculates the monthly interest rate.
- `B4*B5` calculates the total number of monthly payments.
- `B6` provides the amount borrowed.

**Important:** Excel may display the payment as a negative number. This is normal because the payment represents money going out from the borrower's perspective.

If the amount borrowed is entered as a positive value, PMT normally returns a negative payment.

## 5. Making Cell References Absolute

When creating a loan schedule, you may want to copy the PMT formula down a column to calculate the payment for each month.

However, the formula uses the same input cells for every payment. If you drag the formula down without fixing the references, Excel will adjust them automatically.

For example, the original formula is:

```excel
=PMT(B3/B5, B4*B5, B6)
```

If you drag it down one row, Excel may change it to:

```excel
=PMT(B4/B6, B5*B6, B7)
```

This is incorrect because the formula now refers to different cells.

### How to Fix This

Use **absolute cell references** to keep the input cells fixed.

The corrected formula is:

```excel
=PMT($B$3/$B$5, $B$4*$B$5, $B$6)
```

The dollar signs (`$`) prevent the row and column references from changing when the formula is copied.

### Using the F4 Key

In Excel for Windows:

1. Select the cell containing your formula.
2. Click the formula bar and select a cell reference.
3. Press **F4** to toggle through the reference types.
4. Repeat for the other references that need to remain fixed.
5. Press Enter to confirm the formula.

On some laptops, you may need to press `Fn + F4`. Keyboard shortcuts can also vary by Excel version and platform.

## 6. Filling the Loan Schedule

Once the formula contains absolute references, you can copy it down the payment column.

1. Select cell `B9`.
2. Move the pointer to the small square in the bottom-right corner of the cell, called the **fill handle**.
3. When the pointer changes to a black cross, click and drag down the column.
4. Excel copies the formula into the selected cells.

Because the input references are absolute, the formula will continue using the same interest rate, loan term, payment frequency, and borrowing amount.

The monthly payment will remain the same throughout the schedule, assuming the loan uses a fixed interest rate and equal payments.

**Note:** Copying the PMT formula down repeats the payment calculation. It does not, by itself, calculate the changing interest portion, principal portion, or remaining loan balance for each month.

## 7. Important Things to Remember

- **PMT calculates regular payments.** It is commonly used for loans with fixed interest rates and equal payments.
- **Match the interest rate to the payment frequency.** For monthly payments, divide the annual rate by 12 when the rate is quoted annually.
- **Calculate the total number of payments.** Multiply the number of years by the number of payments per year.
- **The loan amount is the `pv` argument.** This is the amount borrowed.
- **Negative payment results are normal.** They represent money paid out by the borrower.
- **Use absolute references when copying formulas.** This keeps the input cells fixed throughout the schedule.
- **The first three arguments are sufficient for a basic calculation.** The optional `fv` and `type` arguments allow you to specify a future balance and payment timing.

## 8. Summary

The PMT function calculates the fixed periodic payment needed to repay a loan.

For a loan with monthly payments, the general formula is:

```excel
=PMT(annual_rate/12, years*12, loan_amount)
```

Using the example worksheet cells, the formula is:

```excel
=PMT($B$3/$B$5, $B$4*$B$5, $B$6)
```

Absolute references make it possible to copy the formula down a loan schedule without changing the input cells.

The PMT function is an important building block for creating a loan amortization schedule in Excel.
