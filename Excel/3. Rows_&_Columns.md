# Rows and Columns

## Deleting Content
- Selecting a column and pressing **Delete** clears the contents of the selected cells without deleting the column itself.

## Inserting Rows and Columns
- To insert a column between existing columns, select a column, right-click, and click **Insert**.
- The same process works for inserting rows.
- When multiple rows or columns are selected before clicking **Insert**, Excel inserts the same number of rows or columns as you selected.
