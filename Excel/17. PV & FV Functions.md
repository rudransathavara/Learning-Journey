# PV and FV Functions

## 1. Introduction to PV and FV

Excel provides two financial functions that help calculate the value of money in different situations:

- **PV (Present Value):** Calculates the present value of a loan or investment based on a constant interest rate, regular payments, and a set number of payment periods.
- **FV (Future Value):** Calculates the future value of an investment based on a constant interest rate and regular payments.

Both functions use similar arguments, but they serve different purposes.

| Function | Full Name | Purpose |
|---|---|---|
| `PV` | Present Value | Calculates the value of a loan or investment in today's terms. |
| `FV` | Future Value | Calculates how much an investment will be worth in the future. |

---

## 2. PV Function (Present Value)

### What Is the PV Function?

The **PV function** calculates the present value of a loan or investment based on a constant interest rate, regular payments, and a specified number of periods.

For example, you can use PV to calculate the principal amount associated with a loan when you know the interest rate, payment amount, and loan term.

### PV Function Syntax

```excel
=PV(rate, nper, pmt, [fv], [type])
```

The function has five arguments. The first three are required, while the last two are optional.

| Argument | Description | Required? |
|---|---|---|
| `rate` | The interest rate for each payment period. | Yes |
| `nper` | The total number of payment periods. | Yes |
| `pmt` | The payment made during each period. | Yes |
| `fv` | The future balance you want to have after the final payment. | No |
| `type` | Specifies when payments are made. | No |

### Understanding the PV Arguments

#### 1. Rate

The interest rate for each payment period.

If the annual interest rate is stored in cell `A2` and payments are made monthly, divide the annual rate by 12.

```excel
=A2/12
```

This converts the annual interest rate into a monthly rate.

#### 2. NPER

The total number of payment periods.

If the loan term is expressed in years but payments are made monthly, multiply the number of years by 12.

For example, a 20-year loan with monthly payments has:

```excel
=20*12
```

This gives 240 monthly payments.

#### 3. PMT

The payment amount made during each period.

For a loan, payments are amounts you owe. Excel uses positive and negative signs to distinguish cash flowing in from cash flowing out.

In the lesson, the payment amount is entered as a negative value because it represents money being paid toward the loan.

#### 4. FV (Future Value)

This optional argument represents the balance you want remaining after the final payment.

For example, it could represent a remaining loan balance or a target cash balance.

If you do not need a specific future balance, you can omit this argument or enter `0`, depending on the calculation.

#### 5. Type

This optional argument specifies when payments are made.

| Type | Meaning |
|---|---|
| `0` or omitted | Payments are made at the end of each period. |
| `1` | Payments are made at the beginning of each period. |

**Important:** The timing of payments affects the result.

### Example: Calculate Present Value for a Loan

Suppose you want to calculate the present value of a loan using:
- An annual interest rate stored in `A2`.
- A loan term in years stored in `B2`.
- A regular payment amount stored in `C2`.
- Monthly payments.
- Payments made at the end of each month.
- No remaining balance after the final payment.

You can use the following formula:

```excel
=PV(A2/12, B2*12, -C2, 0, 0)
```

In this example:
- `A2/12` converts the annual interest rate to a monthly rate.
- `B2*12` converts the loan term in years to the total number of monthly payments.
- `-C2` treats the payment as a cash outflow.
- The first `0` specifies no future balance.
- The final `0` specifies that payments occur at the end of each period.

**Note:** The payment sign determines the sign of the result. If the payment is entered as a negative value directly in the function, the present value will generally be returned as a positive value.

### Using the Insert Function Box

You can use Excel's Insert Function feature to help build a PV formula.

1. Select the cell where you want the result.
2. Click the **Insert Function (fx)** button.
3. Search for `PV`.
4. Select the PV function.
5. Enter the interest rate, number of periods, and payment amount.
6. Enter the future value and payment type if needed.
7. Click **OK**.

Excel calculates the present value based on the values you entered.

## 3. FV Function (Future Value)

### What Is the FV Function?

The **FV function** calculates the future value of an investment based on a constant interest rate and regular payments.

It helps estimate how much an investment may be worth after a certain number of payment periods.

Unlike PV, which calculates present value, FV calculates the value at a future point in time.

### FV Function Syntax

```excel
=FV(rate, nper, pmt, [pv], [type])
```

The FV function has five arguments. The first three are required, while the last two are optional.

| Argument | Description | Required? |
|---|---|---|
| `rate` | The interest rate for each payment period. | Yes |
| `nper` | The total number of payment periods. | Yes |
| `pmt` | The payment made during each period. | Yes |
| `pv` | The present value or initial amount already invested. | No |
| `type` | Specifies when payments are made. | No |

### Understanding the FV Arguments

#### 1. Rate

The interest rate for each payment period.

If the annual interest rate is stored in cell `A2` and the investment is calculated monthly, divide the annual rate by 12.

```excel
=A2/12
```

#### 2. NPER

The total number of payment periods.

For example, if you make one payment every month for 12 months, the number of periods is:

```excel
12
```

If the number of periods is already expressed in months, you do not need to multiply it by 12.

#### 3. PMT

The regular payment made during each period.

For an investment, this could be the amount you contribute regularly.

In the lesson, the payment is entered as a negative value because it represents money being invested.

#### 4. PV (Present Value)

This optional argument represents the amount already invested at the beginning.

For example, if you already have money in an investment account before making additional payments, that initial amount is the present value.

If there is no initial investment, you can omit this argument or enter `0`.

#### 5. Type

This optional argument specifies when payments are made.

| Type | Meaning |
|---|---|
| `0` or omitted | Payments are made at the end of each period. |
| `1` | Payments are made at the beginning of each period. |

If payments are made at the beginning of each period, enter `1`.

If payments are made at the end, enter `0` or leave the argument blank.

### Example: Calculate Future Value for an Investment

Suppose you want to calculate the future value of an investment using:
- An annual interest rate stored in `A2`.
- 12 monthly payments.
- A regular payment amount stored in `C2`.
- An initial investment stored in `D2`.
- Payments made at the beginning of each period.

You can use the following formula:

```excel
=FV(A2/12, 12, -C2, -D2, 1)
```

In this example:
- `A2/12` converts the annual interest rate to a monthly rate.
- `12` represents 12 monthly payment periods.
- `-C2` treats each investment payment as a cash outflow.
- `-D2` treats the initial investment as a cash outflow.
- `1` specifies that payments are made at the beginning of each period.

**Note:** Excel's financial functions use cash-flow signs to distinguish money paid out from money received. The signs you use for `pmt` and `pv` affect whether the result is positive or negative.

### Using the Insert Function Box

You can use Excel's Insert Function feature to help build an FV formula.

1. Select the cell where you want the result.
2. Click the **Insert Function (fx)** button.
3. Search for `FV`.
4. Select the FV function.
5. Enter the interest rate.
6. Enter the total number of payment periods.
7. Enter the regular payment amount.
8. Enter the present value if there is an initial investment.
9. Set the payment type.
10. Click **OK**.

Excel calculates the future value of the investment using the information you entered.

## 4. PV vs. FV

Although PV and FV have similar arguments, they answer different questions.

| Feature | PV (Present Value) | FV (Future Value) |
|---|---|---|
| Main purpose | Calculates present value | Calculates future value |
| Typical use | Calculating a loan or investment's present value | Estimating an investment's future value |
| Interest rate | Required | Required |
| Number of periods | Required | Required |
| Regular payment | Required | Required |
| Additional value argument | Future value (`fv`) | Present value (`pv`) |
| Payment timing | Beginning or end of each period | Beginning or end of each period |

### When Should You Use PV?

Use PV when you want to calculate the present value of a loan or investment based on a known interest rate, payment amount, and number of periods.

### When Should You Use FV?

Use FV when you want to estimate how much an investment will be worth after a specified number of periods, based on a constant interest rate and regular payments.

---

## 5. Important Things to Remember

### Match the Interest Rate to the Payment Period

The interest rate and number of periods must use consistent units.

For example, if payments are monthly:
- Divide the annual interest rate by 12.
- Express the number of periods as the total number of monthly payments.

If payments are annual, use an annual interest rate and a number of annual periods.

### Understand Positive and Negative Values

Excel financial functions use positive and negative values to represent different cash-flow directions.

- Money paid out is generally entered as a negative value.
- Money received is generally entered as a positive value.

The signs of the arguments affect the sign of the calculated result.

### Understand Payment Timing

The `type` argument determines when payments occur.

- `0` or omitted means payments occur at the end of the period.
- `1` means payments occur at the beginning of the period.

The timing can affect the final calculation.

### Use the Insert Function Box

The **Insert Function (fx)** button can help you understand and enter each argument when building PV and FV formulas.

---

## 6. Key Takeaways

- **PV** stands for Present Value and calculates the present value of a loan or investment.
- **FV** stands for Future Value and calculates how much an investment may be worth in the future.
- Both functions use an interest rate, number of periods, and regular payment amount.
- PV uses `fv` as an optional argument for the future balance.
- FV uses `pv` as an optional argument for the initial investment.
- The `type` argument controls whether payments occur at the beginning or end of each period.
- Divide an annual interest rate by 12 when calculating monthly payments using an annual rate.
- Multiply the number of years by 12 when converting a loan term in years into monthly payment periods.
- Pay attention to positive and negative values because Excel uses them to represent cash-flow direction.
