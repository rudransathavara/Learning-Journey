# Sorting and Filtering in Microsoft Excel

## 1. What Are Sorting and Filtering?

Sorting and filtering help you organize data and focus on specific records in a worksheet.

### Sorting

**Sorting** rearranges records into a chosen order.

Examples:
- Alphabetical order, A to Z.
- Reverse alphabetical order, Z to A.
- Smallest to largest.
- Largest to smallest.

### Filtering

**Filtering** temporarily hides records that do not meet your selected criteria.

For example, you can display only records with a particular commission type or amounts greater than 500.

Filtering does not delete the hidden records.

## 2. Why You Should Sort and Filter Entire Records

Each row in a dataset usually represents a complete record.

If you select and sort only one column without including the related data, the values can become separated from the other fields in their records.

To avoid this, use Excel's built-in sorting and filtering tools on the entire dataset.

## 3. Turn on Filters

For this lesson, use the practice file called `Sorting and Filtering`.

### Steps

1. Open the practice file.
2. Click inside the dataset.
3. Go to the **Data** tab.
4. Find the **Sort & Filter** group.
5. Click **Filter**.

Excel adds drop-down arrows to the column headings.

These arrows allow you to sort and filter the data in each column.

**Tip:** Make sure the dataset has clear column headers.

## 4. Sort Data

You can sort a column in ascending or descending order.

### Steps

1. Click the filter arrow in the column you want to sort.
2. Choose the appropriate sorting option.

For text:
- **Sort A to Z** arranges text alphabetically.
- **Sort Z to A** reverses the alphabetical order.

For numbers:
- **Sort Smallest to Largest** arranges values in ascending order.
- **Sort Largest to Smallest** arranges values in descending order.

Excel rearranges the records while keeping the related values in each row together.

## 5. Filter Data by Category

Suppose you want to display only records with a particular commission value.

### Steps

1. Click the filter arrow in the Commission column.
2. Review the available values.
3. Uncheck **Select All**, if necessary.
4. Select the item or items you want to display.
5. Click **OK**.

Excel hides records that do not match your selection.

A funnel icon appears in the filtered column's heading to indicate that a filter is active.

**Important:** The hidden records have not been deleted.

## 6. Use Number Filters

You can filter numerical data using conditions rather than selecting individual values.

For example, suppose you want to see only amounts greater than or equal to 500.

### Steps

1. Click the filter arrow in the Amount column.
2. Select **Number Filters**.
3. Choose **Greater Than Or Equal To**.
4. Enter **500**.
5. Click **OK**.

Excel displays only the records that meet the condition.

You can then sort the remaining records if necessary.

## 7. Clear Filters

You can remove filters without deleting any data.

### Option 1: Clear a Filter in One Column

1. Click the filter arrow in the filtered column.
2. Select **Clear Filter From** the relevant column.

Excel restores the records hidden by that filter.

### Option 2: Clear Filters Using the Ribbon

1. Go to the **Data** tab.
2. Find the **Sort & Filter** group.
3. Click **Clear**.

This clears the active filters.

### Turn Off Filter Arrows

To remove the filter drop-down arrows:

1. Go to the **Data** tab.
2. Click **Filter** again.

The arrows will disappear.

Turning off the filter arrows is different from deleting the underlying records.

## 8. Sort and Filter a PivotTable

PivotTables also provide sorting and filtering options.

If a PivotTable has row and column fields, you can use the drop-down arrows beside their labels to sort or filter the displayed categories.

### Sort PivotTable Categories

1. Open the PivotTable worksheet.
2. Click the arrow beside a row or column label.
3. Choose an ascending or descending sort option.

The PivotTable rearranges the categories.

### Filter PivotTable Categories

1. Click the arrow beside the relevant row or column label.
2. Select or deselect the items you want to display.
3. Apply the filter.

Only the selected categories remain visible in the PivotTable.

## 9. Use Text Filters and Wildcards in a PivotTable

Excel supports text-based filtering in PivotTables.

For example, you might want to display labels that begin with the letter N.

### Steps

1. Open the relevant PivotTable.
2. Click the drop-down arrow beside the row labels.
3. Open **Label Filters** or the available text-filter options.
4. Choose a condition such as **Begins With**.
5. Enter `N`.
6. Apply the filter.

You can also use an asterisk (`*`) as a wildcard in supported text-filter fields.

For example:

`N*`

This pattern represents text beginning with N followed by any number of characters.

**Important:** An asterisk matches any sequence of characters. When using the standard Begins With filter, entering `N` is generally sufficient; you do not need to add `*`.

To remove the PivotTable filter, open the relevant drop-down and choose **Clear Filter**.

## 10. Use an Overall PivotTable Filter

PivotTables also have a Filters area in the PivotTable Field List.

This lets you filter the entire PivotTable using a selected field.

### Steps

1. Click inside the PivotTable.
2. Find the PivotTable Field List.
3. Drag the field you want to filter by into the **Filters** area.
4. Look for the filter above the PivotTable.
5. Open its drop-down arrow.
6. Select the item or items you want to display.

The PivotTable updates to show records that match the selected filter.

### Select Multiple Items

If you want to filter by more than one item:

1. Open the overall filter.
2. Enable **Select Multiple Items**, if available.
3. Check the items you want to include.
4. Apply the selection.

To clear the filter, select all items or use the available clear-filter option.

## 11. Key Takeaways

- Sorting rearranges records into a chosen order.
- Filtering hides records that do not meet selected conditions.
- Use **Data > Filter** to add filter arrows.
- Sort text alphabetically or numbers in ascending or descending order.
- Use Number Filters for conditions such as values greater than or equal to 500.
- Clear filters to restore hidden records.
- Use the PivotTable drop-down arrows to sort or filter categories.
- Drag a field into the PivotTable Filters area to create an overall filter.
- Filtering does not delete the underlying records.
