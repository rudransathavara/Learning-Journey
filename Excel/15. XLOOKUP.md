# XLOOKUP Function

## 1. What Is XLOOKUP?

**XLOOKUP** is a newer Excel function that searches for a value in a range and returns the corresponding information from another range.

Compared with VLOOKUP and INDEX + MATCH, XLOOKUP is:
- Simpler to use.
- Able to return multiple items at once.
- Set to use an exact match by default.

## 2. XLOOKUP Syntax

```excel
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode])
```

XLOOKUP has five possible arguments, but only the first three are required.

| Argument | Description | Required? |
|---|---|---|
| `lookup_value` | The value you want to find. | Yes |
| `lookup_array` | The range where Excel searches for the lookup value. | Yes |
| `return_array` | The range containing the information you want returned. | Yes |
| `if_not_found` | The message or value to return if no match is found. | No |
| `match_mode` | Specifies how Excel matches the lookup value. | No |

## 3. Understanding the Arguments

### Lookup Value

The value you want Excel to find.

For example, if the last name you want to search for is in cell `K6`, the lookup value is:

```excel
K6
```

### Lookup Array

The range where Excel searches for the lookup value.

For example, if last names are stored in cells A5 through A60:

```excel
A5:A60
```

### Return Array

The range containing the information you want Excel to return.

For example, if sales and location are stored in columns D and E:

```excel
D5:E60
```

XLOOKUP can return multiple columns of information from the return array.

### If Not Found

This optional argument lets you specify what Excel should display if it cannot find a matching value.

For example, you could enter a message such as `"Not Found"`.

If you leave this argument blank and no match is found, Excel returns a `#N/A` error.

### Match Mode

This optional argument specifies the type of match Excel should use.

| Value | Meaning |
|---|---|
| `0` | Exact match. This is the default. |
| `-1` | Exact match or the next smaller item. |
| `1` | Exact match or the next larger item. |

**Important:** XLOOKUP defaults to an exact match, so you do not need to specify `0` when an exact match is required.

## 4. Example: Find Sales and Location

Suppose you have a table containing last names, sales figures, and locations.

You want to find the last name **Bilco** and return both the sales figure and location.

### Step 1: Enter the Lookup Value

Enter the last name `Bilco` in cell `K6`.

### Step 2: Identify the Lookup Array

The last names are stored in cells A5 through A60.

```excel
A5:A60
```

### Step 3: Identify the Return Array

The sales figures and locations are stored in columns D and E, from row 5 through row 60.

```excel
D5:E60
```

### Step 4: Write the Formula

```excel
=XLOOKUP(K6, A5:A60, D5:E60)
```

### Step 5: View the Result

Excel searches for the last name in `K6` within `A5:A60`.

When it finds `Bilco`, it returns the corresponding information from columns D and E.

The result includes **both the sales figure and the location**.

This works because the return array includes two columns rather than just one.

## 5. How to Insert XLOOKUP Using the Function Box

You can use Excel's Insert Function feature to help build the formula.

1. Select the cell where you want the result.
2. Click the **Insert Function (fx)** button.
3. Search for `XLOOKUP`.
4. Select the function and open its argument fields.
5. Enter the lookup value.
6. Select the lookup array, excluding the column heading.
7. Select the return array containing the information you want returned.
8. Leave `if_not_found` blank if you do not need a custom message.
9. Leave `match_mode` blank to use the default exact match.
10. Click **OK** to display the result.

## 6. XLOOKUP vs. VLOOKUP vs. INDEX + MATCH

| Feature | VLOOKUP | INDEX + MATCH | XLOOKUP |
|---|---|---|---|
| Finds a matching value | Yes | Yes | Yes |
| Returns information from another column | Yes | Yes | Yes |
| Can return multiple columns in one formula | Not in the same way | Possible with more setup | Yes |
| Requires the lookup column to be the leftmost column of the lookup table | Yes | No | No |
| Defaults to an exact match | No; approximate match is the default if omitted | Depends on the MATCH settings | Yes |
| Ease of use | Relatively simple | Requires combining two functions | Simpler for many lookup tasks |

## 7. Key Takeaways

- **XLOOKUP** searches for a value and returns the corresponding information from another range.
- Its first three arguments are required: `lookup_value`, `lookup_array`, and `return_array`.
- The optional `if_not_found` argument lets you specify what to display when no match is found.
- The optional `match_mode` argument controls how Excel matches values.
- XLOOKUP uses an exact match by default.
- It can return information from multiple columns, such as sales and location, with one formula.
- XLOOKUP is a simpler alternative to VLOOKUP and INDEX + MATCH for many lookup tasks.
