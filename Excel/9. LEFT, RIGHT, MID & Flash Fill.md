# LEFT, RIGHT, MID, and Flash Fill in Excel

## What Are LEFT, RIGHT, and MID?

LEFT, RIGHT, and MID are Excel functions that allow you to extract specific characters from a cell.

They are useful when you want to separate information, such as codes, names, or numbers, without manually typing everything out.

- **LEFT:** Extracts characters from the beginning of a cell.
- **RIGHT:** Extracts characters from the end of a cell.
- **MID:** Extracts characters from a specific position within a cell.

## 1. The LEFT Function

The LEFT function extracts a specific number of characters from the beginning (left-hand side) of a cell.

### Formula Structure

`=LEFT(text, num_chars)`

- **text:** The cell containing the information.
- **num_chars:** The number of characters you want to extract.

### Example

Imagine cell C2 contains a customer location code followed by other information.

To extract the first four characters, use:

`=LEFT(C2, 4)`

This returns the first four characters from cell C2.

### Applying the Formula to Other Cells

1. Enter the formula in the first cell.
2. Press Enter.
3. Select the cell containing the formula.
4. Drag the small square in the bottom-right corner of the cell downwards to apply the formula to other rows.

## 2. The RIGHT Function

The RIGHT function extracts a specific number of characters from the end (right-hand side) of a cell.

### Formula Structure

`=RIGHT(text, num_chars)`

- **text:** The cell containing the information.
- **num_chars:** The number of characters you want to extract.

### Example

Imagine cell E2 contains an office name followed by a four-digit code.

To extract the last four characters, use:

`=RIGHT(E2, 4)`

This returns the final four characters from cell E2.

You can drag the formula down to apply it to the other rows.

## 3. The MID Function

The MID function extracts characters from a specific position within a cell.

Unlike LEFT and RIGHT, you can choose where the extraction begins.

### Formula Structure

`=MID(text, start_num, num_chars)`

- **text:** The cell containing the information.
- **start_num:** The position of the first character you want to extract.
- **num_chars:** The number of characters you want to extract.

### Example

Imagine cell K2 contains a customer satisfaction rate with several decimal places.

To extract three characters starting from the third character, use:

`=MID(K2, 3, 3)`

This extracts three characters, beginning at position three in the cell.

You can adjust the starting position and number of characters depending on the information you need.

**Note:** MID counts characters from the beginning of the cell, including spaces and decimal points.

## 4. Flash Fill

Flash Fill is an Excel tool that recognises a pattern in your data and automatically fills in the remaining cells.

It can help you separate or combine information without writing a formula.

### Example: Extracting First Names

Imagine column B contains customers' full names, such as:

`Antonio Smith`

You want to extract only the first names into column C.

### How to Use Flash Fill

1. Insert a new column next to the original names.
2. Give the new column a heading, such as **First Name**.
3. In the first row, manually type the first name from the full name in the cell beside it.
4. Make sure the name is spelled correctly.
5. Use the keyboard shortcut **Ctrl + E** on Windows to activate Flash Fill.
6. Alternatively, go to the **Data** tab and select **Flash Fill** in the Data Tools group.

Excel will recognise the pattern and attempt to fill in the remaining first names automatically.

## 5. When Should You Use Each One?

| Function or Tool | Purpose | Example |
|---|---|---|
| LEFT | Extracts characters from the beginning | `=LEFT(C2, 4)` |
| RIGHT | Extracts characters from the end | `=RIGHT(E2, 4)` |
| MID | Extracts characters from a specific position | `=MID(K2, 3, 3)` |
| Flash Fill | Automatically fills data by recognising a pattern | Extracting first names from full names |

## Key Takeaways

- LEFT extracts characters from the beginning of a cell.
- RIGHT extracts characters from the end of a cell.
- MID extracts characters from a position you specify.
- Flash Fill recognises patterns and automatically fills in data.
- You can drag formulas down to apply them to multiple rows.
- Flash Fill can sometimes be quicker than writing a formula when separating or combining information.
