# Goal Seek and Scenario Manager

## 1. What Is What-If Analysis?

**What-If Analysis** is a feature in Excel that allows you to explore how changing values in your spreadsheet affects the results.

Two tools covered in this lesson are:

- **Scenario Manager:** Allows you to save and compare different sets of values in the same cells.
- **Goal Seek:** Helps you find the input value needed to achieve a specific result in a formula.

Both tools are available under the **Data** tab in the Excel ribbon.

**Navigation:** Data → What-If Analysis

---

## 2. Scenario Manager

### What Is Scenario Manager?

Scenario Manager allows you to enter different sets of values into the same cells and compare the resulting outcomes.

For example, when calculating a loan payment, you might want to compare different:
- Borrowing amounts.
- Loan terms.
- Interest rates.

Instead of manually changing and recording the values each time, you can save each combination as a separate scenario and switch between them.

### Step 1: Select the Changing Cells

Go to the worksheet where you want to create scenarios.

Select the cells whose values you want to change between scenarios.

In the lesson, the changing cells are:

- `A4`
- `B4`
- `C4`

These cells contain the input values, such as the amount borrowed, loan term, and interest rate.

### Step 2: Open Scenario Manager

1. Go to the **Data** tab.
2. Click **What-If Analysis** in the Forecast group.
3. Select **Scenario Manager**.
4. Click **Add** to create a new scenario.

### Step 3: Create the First Scenario

1. Enter a name for your scenario, such as `First Try`.
2. Check the changing cells to make sure they are correct.
3. Click **OK**.
4. Excel displays the current values in the selected cells.
5. Keep those values or change them as needed.
6. Click **OK** to save the scenario.

Your first scenario is now saved.

### Step 4: Add More Scenarios

Repeat the process to create additional scenarios.

For example, you could create:

| Scenario | Borrowing Amount | Loan Term | Interest Rate |
|---|---|---|---|
| First Try | Current value | Current value | Current value |
| Second Try | Different amount | Different term | Different rate |
| Third Try | Another amount | Another term | Another rate |

These are example descriptions; enter your own values based on your spreadsheet.

For each new scenario:

1. Click **Add** in Scenario Manager.
2. Enter a scenario name.
3. Confirm the changing cells.
4. Click **OK**.
5. Enter the new values.
6. Click **OK** to save the scenario.

You can continue adding scenarios using the same set of changing cells.

### Step 5: Switch Between Scenarios

Once you have created multiple scenarios, you can view their effects without manually entering the values again.

1. Open **Data → What-If Analysis → Scenario Manager**.
2. Select the scenario you want to view.
3. Click **Show**.

Excel updates the changing cells with the values saved in that scenario.

Repeat these steps to switch between scenarios and compare their effects on your calculations.

**Important:** Scenarios are saved with the workbook, so they remain available when you save and reopen the file.

## 3. Create a Scenario Summary Report

Scenario Manager can create a report that compares your scenarios side by side.

This makes it easier to see how different input values affect the results.

### Step 1: Open the Summary Option

1. Go to **Data → What-If Analysis → Scenario Manager**.
2. Click **Summary**.

Excel provides two report options:

- **Scenario Summary:** Creates a report comparing the scenarios.
- **Scenario PivotTable Report:** Creates a PivotTable-based report.

In this lesson, we use the **Scenario Summary** option.

### Step 2: Select the Result Cells

Excel asks you to identify the result cells, also called **result cells**.

These are the cells containing formulas whose results change when you switch scenarios.

In the lesson, the changing input cells are `A4:C4`, and the result cells are:

- `D4`
- `E4`
- `F4`

Select the appropriate result cells in your own worksheet.

### Step 3: Generate the Report

1. Select **Scenario Summary**.
2. Enter or select the result cells.
3. Click **OK**.

Excel creates the Scenario Summary report on a separate worksheet in the workbook.

### Step 4: Review the Report

The report allows you to compare:

- The original or current values.
- The values saved in each scenario.
- The resulting calculations for each scenario.

You can review the scenarios side by side to understand how changing the inputs affects the results.

### Outlining in the Summary Report

Excel may add outlining controls to the report.

These controls allow you to expand or collapse different levels of rows or columns, making the report easier to navigate.

You can use them to show more detail or condense the report when needed.

**Key point:** The Scenario Manager remains available from the original worksheet where the scenarios were created. The saved scenarios remain stored in the workbook.

## 4. Goal Seek

### What Is Goal Seek?

**Goal Seek** is an Excel tool that works backward from a desired result to find the input value needed to achieve it.

For example, suppose you want your monthly loan payment to be `2,000`, but you do not know how much you can borrow to reach that payment.

Instead of manually testing different borrowing amounts, you can use Goal Seek to calculate the required value.

### How Goal Seek Works

Goal Seek uses three main inputs:

| Field | Description |
|---|---|
| **Set cell** | The cell containing the formula whose result you want to achieve. |
| **To value** | The result you want the formula to return. |
| **By changing cell** | The input cell Excel can change to achieve the desired result. |

The set cell must contain a formula, and the changing cell must be part of the calculation that affects that formula.

### Step 1: Open Goal Seek

1. Go to the worksheet containing your calculations.
2. Select the cell containing the formula you want to adjust.
3. Go to the **Data** tab.
4. Click **What-If Analysis**.
5. Select **Goal Seek**.

Goal Seek is the second option in the What-If Analysis menu in the lesson.

### Step 2: Enter the Goal Seek Values

In the lesson, the goal is to achieve a monthly payment of `2,000`.

The formula result is in cell `D4`, and the borrowing amount is the input that needs to change.

Enter the following:

| Goal Seek Field | Value |
|---|---|
| **Set cell** | `D4` |
| **To value** | `2000` |
| **By changing cell** | The cell containing the borrowing amount |

The exact address of the borrowing amount cell depends on the worksheet.

### Step 3: Run Goal Seek

1. Check that all three fields are correct.
2. Click **OK**.
3. Excel attempts to find the input value that produces the desired result.
4. Review the Goal Seek Status box.
5. If the solution is found, review the updated value in the changing cell.

In the lesson, Goal Seek calculates a borrowing amount of approximately `257,965` to achieve a monthly payment of `2,000`.

Your result may differ depending on the values and formulas in your worksheet.

## 5. Scenario Manager vs. Goal Seek

| Feature | Scenario Manager | Goal Seek |
|---|---|---|
| Main purpose | Compare different sets of input values | Find an input value that achieves a desired result |
| How it works | Saves multiple combinations of values | Changes one input cell to target a formula result |
| Number of scenarios or targets | Can save multiple scenarios | Works toward one target result at a time |
| Can compare results | Yes, including through a summary report | Not designed to create a multi-scenario comparison report |
| Example use | Compare different loan amounts, terms, and interest rates | Find the borrowing amount needed for a monthly payment of 2,000 |

### When Should You Use Each Tool?

**Use Scenario Manager when:**
- You want to compare several possible situations.
- You need to test different combinations of values.
- You want to save scenarios and switch between them.
- You want a summary report comparing the results.

**Use Goal Seek when:**
- You already know the result you want.
- You need to find the input value required to reach that result.
- You want Excel to work backward through a formula.

---

## 6. Key Takeaways

- **What-If Analysis** is available under the Data tab in Excel.
- **Scenario Manager** saves different sets of values for the same changing cells.
- You can use the **Show** button to switch between saved scenarios.
- The **Summary** option creates a report comparing scenarios and their results.
- Scenarios are saved with the workbook.
- **Goal Seek** finds an input value that helps achieve a specified formula result.
- Goal Seek requires a formula cell, a target value, and a changing input cell.
- Scenario Manager is useful for comparing possibilities, while Goal Seek is useful for finding a value that meets a specific target.
