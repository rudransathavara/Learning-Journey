# Area Charts in Microsoft Excel

## 1. What Is an Area Chart?

An **area chart** is similar to a line chart, but the area below the line is filled with color.

Both area charts and line charts are useful for showing **trends and changes in data over time**.

- **Line charts:** Display trends using lines and are often better when the chart needs to be printed.
- **Area charts:** Display trends using lines with the area underneath filled in with color.

Choose a chart type that makes your data easy to read and understand.

## 2. Select the Data

Before creating a chart, select the data you want to display.

For this lesson, the practice file is called `Area Charts`.

1. Open the practice file.
2. Select the range **A3:G7**.
3. Exclude the title above the data and row 8, which contains totals.

**Important:** Select only the data you want to represent in your chart.

## 3. Insert an Area Chart

Area charts may not have a dedicated button displayed directly in the Charts group on the ribbon.

Follow these steps to insert one:

1. Select your data.
2. Go to the **Insert** tab.
3. Find the **Charts** group.
4. Click the small **dialog box launcher** in the bottom-right corner of the group. It looks like a small rectangle with a diagonal arrow.
5. In the Insert Chart window, select **All Charts**.
6. Choose **Area** from the categories on the left.
7. Review the available area chart subtypes along the top.
8. Click a subtype to preview how your data will look.
9. Hover over a chart preview to see a larger view.
10. Select the area chart you want.
11. Click **OK**.

Excel will create the area chart on your worksheet.

## 4. Resize and Move the Chart

After inserting the chart, you can adjust its size and position.

- **Resize:** Select the chart and drag one of the corner handles.
- **Move:** Select the chart and drag its border to a new location.

Adjust the chart so that it is large enough to read comfortably.

## 5. Customize the Chart

Excel provides buttons beside a selected chart that let you change its appearance and control what it displays.

### A. Chart Elements

The green **plus sign (+)** is the Chart Elements button.

It allows you to quickly add or remove chart elements, such as:

- Data labels
- A data table beneath the chart

Select the elements you want to display.

### B. Chart Styles

The **paintbrush icon** opens the Chart Styles options.

You can use it to change:

- The overall chart style
- The chart's color scheme

Choose a style that keeps the chart clear and easy to understand.

**Tip:** Avoid styles and colors that make the data difficult to see.

### C. Chart Filters

The **filter icon** lets you control which data series or categories appear in the chart.

To hide an item:

1. Select the chart.
2. Click the **Chart Filters** button.
3. Uncheck the item you want to hide.
4. Click **Apply**.

To show the item again:

1. Open Chart Filters.
2. Check the item again.
3. Click **Apply**.

**Important:** Filtering an item out of a chart does not delete the original data. You can restore the item by selecting it again and applying the filter.

## 6. Key Takeaways

- Area charts are similar to line charts, but the area below the line is filled with color.
- Both chart types are useful for displaying trends.
- Line charts are often a better choice when printing is a priority.
- Select only the relevant data before inserting a chart.
- Use **Insert > Charts > Dialog Box Launcher > All Charts > Area** to find area chart options.
- Use Chart Elements to add items such as data labels.
- Use Chart Styles to change the chart's appearance and colors.
- Use Chart Filters to show or hide items without deleting the source data.
- Keep charts simple, readable, and visually clear.
