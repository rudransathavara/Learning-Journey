# Introduction to Microsoft Excel

## What Is Microsoft Excel?

Microsoft Excel is a spreadsheet application used to organise and manage data.

## Basic Excel Terminology

- **Workbook:** An Excel file that can contain multiple worksheets.
- **Worksheet:** A spreadsheet within a workbook.
- **Rows:** Horizontal lines identified by numbers.
- **Columns:** Vertical lines identified by letters.
- **Cells:** Individual boxes where data is entered.
- **Cell Reference:** The location of a cell, such as A1 or B2.
- **Ribbon:** The toolbar containing Excel tools and commands.
- **Formula Bar:** The area displaying the contents of a selected cell.

## Worksheets and Sheets

- **Sheets:** Tabs at the bottom of an Excel workbook that allow you to switch between worksheets.
- **Creating a New Sheet:** Click the **+ (plus) button** next to the sheet tabs at the bottom of the workbook.
- **Renaming a Sheet:** Double-click the sheet tab, type the new name, and press Enter.
- **Switching Between Sheets:** Click the sheet tab you want to open.
- **Deleting a Sheet:** Right-click the sheet tab and select **Delete**.
- **Reordering Sheets:** Click and drag a sheet tab to move it to a different position.

A workbook can contain multiple sheets, allowing you to organise different sets of information within one Excel file.
