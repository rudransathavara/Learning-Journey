# Building a Rate of Return Calculator in Excel

## Overview

A **rate of return (RoR)** measures the gain or loss on an investment over a specified period, expressed as a percentage of the initial investment.

It helps investors and businesses assess investment performance and compare different investment opportunities.

Rates of return can be calculated over various periods, including daily, monthly, quarterly and annually.

In this exercise, we focus on **Holding Period Return (HPR)**, which measures the total return over a specific investment period.

## Why Is Rate of Return Important?

Rate of return analysis helps investors and businesses:

- Measure investment performance.
- Compare different investments.
- Identify gains and losses over time.
- Evaluate historical investment results.
- Make more informed decisions about allocating capital.

## Understanding Holding Period Return (HPR)

**Holding Period Return (HPR)** measures the total return on an investment over the period it is held.

The basic formula is:

**HPR = (Ending Value − Beginning Value) ÷ Beginning Value**

To express the result as a percentage, multiply by 100 or format the result as a percentage in Excel.

### Example

Suppose an investment increases in value from £1,000 to £1,200.

Calculation:

`(£1,200 − £1,000) ÷ £1,000 = 0.20`

The holding period return is **20%**.

If the investment decreases from £1,000 to £900:

`(£900 − £1,000) ÷ £1,000 = -0.10`

The holding period return is **-10%**.

This formula measures the return based on the beginning and ending values. When using adjusted share prices, it can also reflect the effects of dividends and stock splits.

## Preparing the Data in Excel

Once the historical data is open in Excel, you need to organise it before calculating HPR.

### Step 1: Identify the Required Columns

The two main fields needed for this exercise are:

- **Date:** Identifies the period associated with each observation.
- **Adjusted Close:** The adjusted closing share price.

Adjusted closing prices account for relevant corporate actions, such as stock splits and dividends, according to the data provider's methodology.

Using adjusted closing prices can provide a more representative measure of historical investment returns than using unadjusted closing prices alone.

### Step 2: Remove Unnecessary Columns

If the downloaded dataset contains additional fields that are not needed:

1. Identify the columns required for your calculations.
2. Select the unnecessary columns.
3. Delete them if you do not need them for any other analysis.

Keep the Date and Adjusted Close columns.

### Step 3: Create an HPR Column

Add a new column labelled:

`HPR`

This column will contain the return calculated between consecutive observations.

### Step 4: Create a Summary Section

Create a small summary area for the following metrics:

- Arithmetic Mean Return
- Geometric Mean Return

These metrics help summarise the returns calculated over the selected period.

## Calculating HPR in Excel

Assume:

- Column A contains Date.
- Column B contains Adjusted Close.
- Column C will contain HPR.

The following example assumes the first observation is in row 2.

### Step 1: Calculate the First Period Return

The first return requires two consecutive adjusted closing prices.

In cell C3, enter:

`=(B3-B2)/B2`

This calculates the return from the value in B2 to the value in B3.

### Step 2: Press Enter

Excel calculates the return as a decimal.

For example:

- `0.05` represents a 5% return.
- `-0.03` represents a -3% return.
- `0.12` represents a 12% return.

### Step 3: Copy the Formula Down

1. Select cell C3.
2. Use the fill handle to copy the formula down the column.
3. Check that the formula references consecutive rows correctly.

Each row will calculate the return between the current observation and the preceding observation.

### Step 4: Format the Returns as Percentages

1. Select the HPR values.
2. Go to the **Home** tab.
3. Click **Percent Style (%)**.
4. Increase or decrease the decimal places as needed.

You can also use the keyboard shortcut `Ctrl + Shift + %` in Windows Excel to apply percentage formatting.

**Important:** Percentage formatting changes how the value is displayed, not the underlying calculation.

## Calculating the Arithmetic Mean Return

The arithmetic mean return is the simple average of the individual period returns.

It is calculated by adding the returns together and dividing by the number of observations.

### Step 1: Select the Summary Cell

Choose the cell where you want the arithmetic mean return to appear.

For example, if your returns are in cells C3:C26, enter:

`=AVERAGE(C3:C26)`

Adjust the range to match your dataset.

### Step 2: Press Enter

Excel calculates the average of the periodic returns.

### Step 3: Format the Result

1. Select the result cell.
2. Apply percentage formatting.
3. Display two decimal places if appropriate.

### Interpretation

The arithmetic mean return represents the average return per period.

However, it does not account for the compounding effect that occurs when investment returns build on one another.

For that reason, it should not automatically be treated as the annualised or compounded return.

## Calculating the Geometric Mean Return

The geometric mean return accounts for the compounding effect of returns over multiple periods.

It is particularly useful when analysing investment performance across several periods.

### Formula

**Geometric Mean Return = [(1 + R₁) × (1 + R₂) × ... × (1 + Rₙ)]^(1/n) − 1**

Where:

- R₁, R₂ and subsequent values represent individual period returns.
- n represents the number of periods.

Excel's `GEOMEAN` function can also be used when applied to positive growth factors.

### Using GEOMEAN in Excel

Assume the periodic returns are in cells C3:C26.

Enter:

`=GEOMEAN(1+C3:C26)-1`

This illustrates the intended calculation, but **the formula as written may require array calculation in older Excel versions**. In modern Excel versions that support dynamic array calculations, it can be entered directly.

For a more broadly compatible approach, create a separate column containing the growth factor for each period.

For example, in D3, enter:

`=1+C3`

Copy the formula down the column.

Then calculate the geometric mean return:

`=GEOMEAN(D3:D26)-1`

Format the result as a percentage.

**Important:** The growth factors supplied to `GEOMEAN` must be positive. A return of -100% produces a growth factor of zero, which cannot be used in this calculation.

### Interpretation

The geometric mean return represents the constant per-period compounded return that would produce the same cumulative growth over the selected periods.

For example, a geometric mean of 2% across monthly periods represents an average compounded monthly growth rate of 2%.

It is not the same as an annual return unless the period and annualisation are handled appropriately.

## Arithmetic Mean vs Geometric Mean

| Metric | Purpose | Compounding |
|---|---|---|
| Arithmetic Mean Return | Calculates the simple average of periodic returns. | Does not directly account for compounding. |
| Geometric Mean Return | Calculates the average compounded growth rate. | Accounts for compounding. |

The geometric mean is generally more suitable for summarising compounded investment performance across multiple periods.

## Important Tips

- **Use adjusted closing prices carefully:** They can help account for dividends and stock splits.
- **Check the date order:** The return formula assumes that each row follows the preceding observation chronologically.
- **Use consecutive observations:** Each HPR calculation should compare two adjacent periods.
- **Format returns as percentages:** This makes the results easier to interpret.
- **Understand the frequency:** Monthly returns should not be confused with annual returns.
- **Check for missing data:** Missing observations can affect the period being measured.
- **Distinguish average returns from compounded returns:** Arithmetic and geometric means answer different questions.

## Key Takeaways

- HPR measures the percentage gain or loss over a specified holding period.
- The basic formula compares ending value with beginning value.
- Historical adjusted closing prices can be used to calculate investment returns.
- The arithmetic mean calculates the simple average of periodic returns.
- The geometric mean accounts for compounding.
- Excel formulas can automate these calculations across many periods.
