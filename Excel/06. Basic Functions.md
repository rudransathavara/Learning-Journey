# Basic Functions in Excel

## 1. SUM Function

The **SUM** function adds together numbers in a selected range of cells.

### How to use SUM
1. Select the cell where you want the total to appear.
2. Type `=SUM(`.
3. Select the range of cells you want to add together.
4. Type `)` and press **Enter**.

**Example:**

`=SUM(A1:A5)`

This adds all the numbers in cells A1 to A5.

---

## 2. AVERAGE Function

The **AVERAGE** function calculates the mean of a selected range of numbers.

### How to use AVERAGE
1. Select the cell where you want the result to appear.
2. Type `=AVERAGE(`.
3. Select the range of cells.
4. Type `)` and press **Enter**.

**Example:**

`=AVERAGE(A1:A5)`

This calculates the average of the numbers in cells A1 to A5.

## 3. MAX Function

The **MAX** function finds the largest number in a selected range of cells.

### How to use MAX
1. Select the cell where you want the result to appear.
2. Type `=MAX(`.
3. Select the range of cells.
4. Type `)` and press **Enter**.

**Example:**

`=MAX(A1:A5)`

## 5. COUNT NUMBERS Function

The **COUNT** function counts how many cells in a selected range contain numbers. It does not count text entries or blank cells.

### How to use COUNT
1. Select the cell where you want the result to appear.
2. Type `=COUNT(`.
3. Select the range of cells.
4. Type `)` and press **Enter**.

**Example:**

`=COUNT(A1:A5)`

This counts how many cells in A1 to A5 contain numbers.

---

## Key Takeaways

- **SUM:** Adds numbers together.
- **AVERAGE:** Calculates the average of a range.
- **MAX:** Finds the largest number.
- **MIN:** Finds the smallest number.
- **COUNT:** Counts cells containing numbers.

**Tip:** In these examples, `A1:A5` represents the range from cell A1 to cell A5. You can replace it with any range you need.
