# VLOOKUP in Excel

## What Is VLOOKUP?

VLOOKUP stands for **Vertical Lookup**.

It is an Excel function that searches for a value in the first (leftmost) column of a table and returns information from another column on the same row.

VLOOKUP is useful when you need to find information quickly without manually searching through a spreadsheet.

For example, you can use VLOOKUP to find a customer's annual spending based on their customer number.

## 1. The VLOOKUP Function

### Formula Structure

`=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])`

The formula has four arguments:

- **lookup_value:** The value you want Excel to search for.
- **table_array:** The range of cells containing the information you want to search.
- **col_index_num:** The column number within the selected table that contains the information you want returned.
- **range_lookup:** Determines whether Excel looks for an exact or approximate match. This argument is optional.

## 2. Understanding the Arguments

### Lookup Value

The lookup value is the information Excel will search for.

For example, if cell M2 contains a customer number, you can use M2 as your lookup value.

### Table Array

The table array is the range of cells containing both the value you want to find and the information you want returned.

For example, your table might contain customer numbers, customer names, and annual costs.

**Important:** The column containing your lookup value must be the leftmost column of the selected table array.

The table array can also be located in a different workbook.

### Column Index Number

The column index number tells Excel which column contains the information you want returned.

Excel counts the columns from left to right within the selected table array, starting at 1.

For example:

| Column in Table Array | Column Index Number |
|---|---:|
| First column | 1 |
| Second column | 2 |
| Third column | 3 |
| Fourth column | 4 |
| Ninth column | 9 |

**Important:** You must enter a number, not a column letter such as I.

### Range Lookup

The range lookup argument determines the type of match Excel uses.

- **FALSE:** Finds an exact match.
- **TRUE:** Finds an approximate match.

If you leave this argument out, Excel uses approximate matching by default.

For customer numbers and other values that must match exactly, use `FALSE` to ensure Excel looks for the correct value.

## 3. Example: Finding a Customer's Annual Cost

Imagine you have a table containing customer numbers and their annual ticket costs.

You enter a customer number into cell M2 and want Excel to return that customer's annual cost.

Use the following formula in cell N2:

`=VLOOKUP(M2, A1:I23, 9, FALSE)`

This example assumes the table array is in cells A1:I23, with customer numbers in column A and annual costs in column I.

The formula works as follows:

1. **M2:** Excel reads the customer number you entered.
2. **A1:I23:** Excel searches within the selected table.
3. **9:** Excel returns the value from the ninth column of the table array.
4. **FALSE:** Excel requires an exact match for the customer number.

Excel then returns the annual cost for the matching customer.

If you change the customer number in M2, the result updates automatically to show the annual cost for the new customer.

## 4. Using the Insert Function Box

If you are new to VLOOKUP, Excel's Insert Function box can help you enter the correct arguments.

1. Select the cell where you want the result.
2. Click the **fx** button beside the formula bar.
3. Search for `VLOOKUP`.
4. Select the function.
5. Enter the lookup value.
6. Select the table array.
7. Enter the column index number.
8. Enter `FALSE` if you need an exact match.
9. Click OK to calculate the result.

## Key Takeaways

- VLOOKUP stands for Vertical Lookup.
- It searches for a value in the leftmost column of a table.
- It returns information from another column on the same row.
- The column index number counts columns from left to right, starting at 1.
- Use `FALSE` when you need an exact match.
- If the lookup value changes, the returned result updates automatically.
- VLOOKUP is useful for finding information quickly without manually searching through large tables.
