# Pie and Donut Charts in Microsoft Excel

## 1. What Are Pie Charts?

A **pie chart** is used to show how individual categories contribute to a whole. Each slice represents a category's share of the total.

Pie charts are useful for visualizing proportions or percentages, making it easy to compare how much each category contributes.

For example, a pie chart could show how much of a company's total sales comes from each customer representative.

### Types of Pie Charts in Excel

Excel offers different chart options, including:

- **2-D Pie:** A standard pie chart displayed in two dimensions.
- **3-D Pie:** A pie chart with a three-dimensional appearance.
- **Doughnut:** A ring-shaped chart with a hole in the center.

You can hover over chart options in Excel to preview how your data will look.

## 2. Create a Pie Chart

For this lesson, use the practice file provided with the course.

### Step 1: Select the Data

Select the range **A2:D3**, including the headings and the data for the top customer representatives.

**Tip:** Include the relevant headings so Excel can identify the categories correctly.

### Step 2: Insert the Chart

1. Select the data.
2. Go to the **Insert** tab.
3. Find the **Charts** group.
4. Open the pie chart options.
5. Hover over the available chart types to preview them.
6. Select **3-D Pie**.

Excel will create the pie chart on your worksheet.

## 3. Change the Data Displayed in a Pie Chart

One useful feature of pie charts is that you can adjust the range of cells used by the chart.

For example, you may want to display a different customer representative instead of the one currently shown.

To adjust the chart's data range:

1. Click the pie chart to select it.
2. Locate the colored outline around the cells being used as the chart's source data.
3. Move the mouse pointer to the corner of the outlined range.
4. When the pointer changes to a double-headed arrow, click and drag the range boundary.
5. Adjust the range to include the data you want to display.

Excel will update the chart to reflect the changed data range.

**Important:** Make sure the adjusted range includes the appropriate category labels and corresponding values.

## 4. What Are Doughnut Charts?

A **doughnut chart** is similar to a pie chart, but it has a hole in the center.

Like pie charts, doughnut charts show how categories contribute to a whole.

However, doughnut charts can represent multiple data series, making them useful when you need to compare more than one row of related data.

### Pie Chart vs. Doughnut Chart

| Feature | Pie Chart | Doughnut Chart |
|---|---|---|
| Appearance | Solid circle divided into slices | Ring divided into segments |
| Shows proportions of a whole | Yes | Yes |
| Multiple data series | Generally designed for one series | Can display multiple data series |
| Best suited for | Showing one set of category proportions | Comparing proportions across multiple data series |

**Tip:** Choose the chart type that makes your data easiest to interpret.

## 5. Create a Doughnut Chart

In the practice file, follow these steps:

### Step 1: Select the Data

1. Click a normal worksheet cell outside the existing pie chart.
2. Select the range **A2:D6**.

This range includes the headings and multiple rows of data.

### Step 2: Insert the Chart

1. Go to the **Insert** tab.
2. Open the chart options in the **Charts** group.
3. Find the **Doughnut** chart subtype.
4. Select it.

Excel will create a doughnut chart based on the selected data.

Because the selected range contains multiple rows of data, the doughnut chart can display more than one data series.

## 6. Edit and Format Pie and Doughnut Charts

After creating either chart, you can change its appearance and layout without changing the chart type.

### A. Use the Chart Buttons

When you select a chart, buttons appear near its upper-right corner.

Depending on the chart and Excel version, these buttons can help you:

- Add or remove chart elements.
- Change the chart's visual style.
- Filter the data displayed in the chart.

### B. Use the Chart Design Tab

On Excel for Windows, selecting a chart displays contextual ribbon tabs, including **Chart Design**.

The Chart Design tab provides tools for:

- Choosing different chart styles.
- Changing the chart layout.
- Adding or adjusting chart elements.
- Updating the chart's data.

These options let you improve the chart's appearance without needing to recreate it.

### C. Use the Format Tab

The contextual **Format** tab provides additional formatting options for chart elements.

Use it to adjust the appearance of selected elements and improve the overall presentation.

**Tip:** Keep your chart clear and readable. Avoid unnecessary colors or decorative effects that make the data harder to understand.

## 7. Key Takeaways

- Pie charts show how categories contribute to a whole.
- Each pie slice represents a category's share of the total.
- Excel provides 2-D Pie, 3-D Pie, and Doughnut chart options.
- You can adjust a pie chart's source data range by dragging the range boundary.
- Doughnut charts have a hole in the center and can display multiple data series.
- Select **A2:D3** to create the example pie chart.
- Select **A2:D6** to create the example doughnut chart.
- Use the Chart Design and Format tabs to customize charts.
- Choose the chart type that best communicates your data.
