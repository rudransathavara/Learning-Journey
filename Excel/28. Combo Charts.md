# Combo Charts in Microsoft Excel

## 1. What Is a Combo Chart?

A **combo chart** combines two different chart types into a single chart.

For example, you can combine:
- A column chart and a line chart.
- An area chart and a line chart.

Combo charts are useful when you want to compare different types of data in one visual.

You can create a combo chart using a single data set or multiple data series that share a common category field.

### Example: Sales Totals and Commission Fees

In this lesson, a combo chart is used to compare **sales totals** with **commission fees**.

The chart uses:
- **Clustered columns** to represent sales totals.
- **A line** to represent commission fees.

This makes it easier to compare the two measures in one chart.

## 2. Select the Data

Before creating the chart, select the data you want to display.

For this lesson, use the provided Excel practice file.

1. Click cell **A3**.
2. Select the range **A3:C8**.
3. Make sure you include the relevant column headings and data.
4. Do not include the worksheet title or totals row.

**Important:** Selecting the correct range helps Excel identify the categories and data series for your chart.

## 3. Insert a Combo Chart

Follow these steps to create a combo chart:

1. Select the range **A3:C8**.
2. Go to the **Insert** tab.
3. Find the **Charts** group.
4. Click the **Combo Chart** button, represented by a column chart with a line over it.
5. Review the available combo chart options.
6. Select **Clustered Column – Line on Secondary Axis**, the middle option in the example.
7. Excel will create the combo chart.

The chart displays sales totals as columns and commission fees as a line.

### Why Use a Secondary Axis?

Sales totals and commission fees may have very different numerical values.

For example, sales totals might be in the thousands, while commission fees might be much smaller.

If both series use the same vertical axis, the smaller values may be difficult to see.

A **secondary axis** gives one data series its own vertical scale, making it easier to display and compare both series in the same chart.

## 4. Change the Combo Chart Type

You can change the chart types assigned to each data series after creating the chart.

To do this:

1. Right-click the combo chart.
2. Select **Change Chart Type**.
3. In the chart settings window, review the chart types assigned to each data series.

You will see which chart type is being used for each series.

For example:
- Sales Total may be displayed as a clustered column.
- Commission Fee may be displayed as a line.

You can change these settings to suit your data.

### Switch the Chart Types

If you want to switch how the data is displayed:

1. Find the data series you want to change.
2. Select a different chart type from its drop-down menu.
3. Repeat for other series if necessary.
4. Click **OK** to apply your changes.

Excel updates the chart using your selected combination of chart types.

**Tip:** Choose chart types that make the relationship between your data series easy to understand.

## 5. Use or Remove the Secondary Axis

In the **Change Chart Type** window, you can also control whether a data series uses a secondary axis.

Depending on your data, you can:
- Enable a secondary axis for one series.
- Display both series using the primary axis.

### When Should You Use a Secondary Axis?

Use a secondary axis when the data series have substantially different scales and one series is difficult to see on the primary axis.

If both series have similar values and units, a single axis may be sufficient.

**Important:** Label your axes clearly when using two scales so viewers can interpret the chart correctly.

## 6. Customize the Combo Chart

After choosing the chart types and axes, you can improve the chart's layout and appearance.

### Use the Chart Design Tab

When you select a chart in Excel, the contextual **Chart Design** tab appears.

This tab includes tools for changing the chart's appearance and layout.

### Use Quick Layout

To try different chart layouts:

1. Select the chart.
2. Go to the **Chart Design** tab.
3. Click **Quick Layout**.
4. Review the available layouts.
5. Select the layout that best presents your data.

Quick Layout lets you change the arrangement of chart elements without changing the underlying data.

When you finish editing, click outside the chart to return to the worksheet.

## 7. Key Takeaways

- A combo chart combines two chart types in one visual.
- It is useful for comparing related data series, such as sales totals and commission fees.
- Excel offers several built-in combo chart options.
- You can create a combo chart using **Insert > Combo Chart**.
- The clustered column and line combination displays one series as columns and another as a line.
- A secondary axis is useful when the data series have significantly different scales.
- Use **Right-click > Change Chart Type** to customize each data series.
- Use **Chart Design > Quick Layout** to quickly adjust the chart's layout.
- Choose chart types and axis settings that make the data clear and easy to interpret.
