# Football Field Charts in Microsoft Excel

## 1. What Is a Football Field Chart?

A **football field chart** is a floating bar chart commonly used in financial valuation.

It displays valuation ranges from several different valuation methods side by side, allowing analysts to compare the estimated value of a company.

Despite its name, it is not used to track football scores. The chart gets its name from its appearance, which resembles a football field.

### Common Uses

Football field charts are often used in investment banking, corporate finance, and company valuation.

A valuation analysis may include methods such as:

- **Discounted Cash Flow (DCF):** Estimates a company's value based on projected future cash flows.
- **Leveraged Buyout (LBO):** Evaluates a company's value in the context of a leveraged buyout transaction.
- **Other valuation methods:** Provide additional estimates based on different assumptions and approaches.

The chart helps viewers compare these valuation ranges in one place.

## 2. Understand the Chart Structure

In this lesson, the football field chart is created using an Excel stock chart.

The example uses an **Open-High-Low-Close stock chart** to display valuation ranges.

The selected data contains four numerical values for each valuation method:

- Open
- High
- Low
- Close

The chart can then be customized to show the valuation methods as category labels and display the high and low values clearly.

Although Excel's stock chart is designed for financial data, this chart type can be adapted for a football field valuation chart when the source data is structured appropriately.

## 3. Select the Data

For this lesson, use the practice file called `Create Football Field Charts`.

1. Open the practice file.
2. Select the range **B3:E7**.
3. Do not include the valuation method labels in column A at this stage.

Unlike many other charts, the instructor adds the category labels after creating the chart.

## 4. Insert the Stock Chart

Follow these steps:

1. Select **B3:E7**.
2. Go to the **Insert** tab.
3. Find the **Charts** group.
4. Click the small dialog box launcher in the bottom-right corner of the group.
5. In the Insert Chart window, select **All Charts**.
6. Choose **Stock** from the chart categories on the left.
7. Select the second stock chart option, **Open-High-Low-Close**.
8. Click **OK**.

Excel creates the initial chart.

Resize the chart so that it is wide enough to display the valuation ranges clearly.

## 5. Add the Correct Category Labels

The initial chart may not display the valuation method names along the horizontal axis.

To add them:

1. Right-click a data bar in the chart.
2. Select **Select Data**.
3. Find the category axis labels section.
4. Click **Edit**.
5. Select the range **A3:A7**, which contains the valuation method names.
6. Click **OK**.
7. Click **OK** again to close the Select Data window.

The valuation method names should now appear along the horizontal axis.

### Remove Unnecessary Chart Elements

The instructor removes the legend and gridlines to simplify the chart.

To remove the legend:

1. Click the legend.
2. Press **Delete**.

To remove the gridlines:

1. Click the gridlines.
2. Press **Delete**.

These elements may be unnecessary when they do not add useful information to the chart.

## 6. Add Data Labels for the High Values

Data labels make it easier to identify the high and low values in each valuation range.

First, add labels for the high values.

### Steps

1. Click a data bar to select the data series.
2. Click the top-middle marker of a data bar to select the high-value data points.
3. Open **Chart Elements** using the green plus sign, if available.
4. Select **Data Labels**.
5. Open the options arrow beside Data Labels.
6. Select **More Options** to open the Format Data Labels pane.
7. Under **Label Position**, select **Above**.
8. Expand **Number**.
9. Choose **Currency**.
10. Set the number of decimal places to **2**.

The high values should now appear above the valuation ranges, formatted as currency.

**Tip:** Use the correct currency format for the data in your own workbook.

## 7. Add Data Labels for the Low Values

Next, add labels for the low values.

### Steps

1. Close the Format Data Labels pane if necessary.
2. Click the bottom-middle marker of a data bar to select the low-value data points.
3. Open **Chart Elements** using the green plus sign.
4. Select **Data Labels**.
5. Open the options arrow and choose **More Options**.
6. In the Format Data Labels pane, set **Label Position** to **Below**.
7. Expand **Number**.
8. Choose **Currency**.
9. Set the number of decimal places to **2**.

The low values should now appear below the valuation ranges.

### Why Add Both High and Low Labels?

Displaying both values makes the valuation range easier to understand without requiring the viewer to estimate the values from the vertical axis.

## 8. Format the Data Series

You can improve the appearance of the chart by formatting the data bars.

### Steps

1. Click a data bar to select the data series.
2. Right-click the selected series.
3. Choose **Format Data Series** or the equivalent formatting option shown in your Excel version.
4. Open the Fill and Line options.
5. Under **Fill**, select **Solid Fill**.
6. Choose a color that is easy to see.
7. Under **Border**, select **No Line**.

A simple fill color and no border can make the chart look cleaner.

**Tip:** Avoid colors that are so dark that they compete with the data labels.

## 9. Add a Chart Title

The chart needs a meaningful title.

For this example, use:

**Evaluation Summary – Equity Value per Share (in Dollars)**

To edit the chart title:

1. Click the chart title.
2. Select the title text.
3. Enter the new title.

The instructor also demonstrates entering title text through the formula bar and pressing Enter.

A descriptive title helps viewers understand what the chart represents and the units being used.

## 10. Format the Chart Area

You can also format the chart area to create a clean background.

### Steps

1. Click the chart area.
2. Right-click and select **Format Chart Area**.
3. Open the Fill and Line options.
4. Under **Fill**, choose **No Fill** or a solid white fill.
5. Under **Border**, select **No Line**.

The instructor uses a simple background and removes the chart border to reduce visual clutter.

## 11. Format the Vertical Axis

The vertical axis represents the valuation scale.

In the example, the instructor sets the minimum axis value to 10 to spread out the chart and make the valuation ranges easier to distinguish.

### Change the Minimum Value

1. Click the vertical axis.
2. Right-click and choose **Format Axis**.
3. Find the **Bounds** settings.
4. Set the minimum value to **10**.

The chart will update to use the new minimum value.

**Important:** Choose a minimum value that is appropriate for your data. Starting an axis above zero can make differences appear larger, so use this adjustment carefully and make sure the chart is not misleading.

### Format the Axis Line

The instructor also adds a visible axis line.

1. Select the vertical axis.
2. Open the Format Axis pane.
3. Select the **Fill & Line** options.
4. Under **Line**, select **Solid Line**.
5. Choose a gray color.
6. Set the width to approximately **2 pt**.

This makes the axis easier to distinguish from the chart itself.

## 12. Format the Horizontal Axis

The horizontal axis displays the valuation method names.

To format it:

1. Click the horizontal axis.
2. Right-click and select **Format Axis**.
3. Open the **Fill & Line** options.
4. Under **Line**, select **Solid Line**.
5. Choose the same gray color used for the vertical axis.
6. Set the width to approximately **2 pt**.

Using consistent formatting for both axes creates a more professional appearance.

## 13. Add a Reference Line for a Target Share Price

A football field chart can include a reference line representing a target share price or another important benchmark.

In this example, the instructor adds a dashed orange line at the 40-dollar share-price level.

### Step 1: Insert a Line

1. Click outside the chart.
2. Go to the **Insert** tab.
3. Select **Shapes**.
4. Choose the **Line** shape.
5. Draw a horizontal line across the chart.

### Step 2: Format the Line

1. Right-click the line.
2. Select **Format Shape**.
3. Open the Fill and Line options.
4. Under **Line**, select **Solid Line**.
5. Choose an orange color.
6. Set the width to approximately **2 pt**.
7. Choose a dashed line style.

### Step 3: Position the Line

1. Move the line into the chart.
2. Position it at the appropriate share-price level.
3. Hold down **Shift** while drawing or resizing the line to help keep it horizontal.

The dashed line provides a visual benchmark that viewers can compare against the valuation ranges.

**Important:** A manually drawn line is a visual annotation. If the chart's axis scale changes, you may need to reposition it to keep it aligned with the intended value.

## 14. Review the Finished Chart

Before completing the chart, check that:

- The valuation method names appear along the horizontal axis.
- High values are labeled above the ranges.
- Low values are labeled below the ranges.
- Currency values display two decimal places.
- The chart has a clear title.
- The chart background and axes are easy to read.
- The reference line is positioned at the intended share-price level.
- The chart presents the valuation ranges clearly without unnecessary clutter.

## 15. Key Takeaways

- Football field charts compare valuation ranges from multiple methods.
- They are commonly used in investment banking and corporate finance.
- Excel's stock chart feature can be adapted to create a football field chart.
- Select **B3:E7** to create the initial stock chart.
- Use **Select Data** to assign category labels from **A3:A7**.
- Add high and low data labels to show valuation ranges clearly.
- Format the labels as currency with two decimal places.
- Use chart and axis formatting to improve readability.
- Add a reference line to represent a target share price or another important benchmark.
- Make sure all formatting choices support accurate interpretation of the data.
