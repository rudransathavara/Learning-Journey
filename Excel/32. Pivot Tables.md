# Pivot Tables in Microsoft Excel

## 1. What Is a Pivot Table?

A **PivotTable** is an Excel tool that summarizes and analyzes large amounts of data.

It allows you to organize selected fields into rows, columns, filters, and values without changing the original source data.

PivotTables are useful when you need to:
- Calculate total sales by destination.
- Compare results across offices.
- Calculate average values for different categories.
- Summarize large datasets quickly.
- Rearrange data to answer different business questions.

For example, you might need to calculate total sales or commission by destination. A PivotTable can summarize the relevant fields without requiring many separate formulas.

## 2. Prepare Your Source Data

Before creating a PivotTable, make sure your data is organized properly.

### Important Requirements

**1. Include column headers**

Each column should have a clear heading in the first row of the dataset.

Examples include:
- Office
- Destination
- Commission
- Amount
- Tickets
- Total

Column headers become the field names in the PivotTable Field List.

**2. Avoid completely blank rows**

An entirely blank row inside your dataset can cause Excel to detect an incomplete source range.

Blank cells within otherwise populated rows are generally acceptable, but complete blank rows should be avoided.

**3. Keep data organized**

Each row should represent a record, with related information stored in separate columns.

## 3. Create a Recommended PivotTable

Excel can suggest PivotTables based on your source data.

For this lesson, use the practice file called `Create Pivot Tables`.

### Steps

1. Open the practice file.
2. Click any cell inside the source data.
3. Go to the **Insert** tab.
4. Select **Recommended PivotTables**.
5. Review the suggested layouts.
6. Select a PivotTable that answers your question.
7. Click **OK**.

Excel creates the recommended PivotTable on a new worksheet.

The original source data remains on its original worksheet.

**Tip:** Recommended PivotTables are a useful starting point when you are unfamiliar with the available fields or unsure how to summarize your data.

## 4. Create a PivotTable Manually

You can also create a PivotTable from scratch.

### Steps

1. Click any cell inside your source data.
2. Go to the **Insert** tab.
3. Click the top portion of the **PivotTable** button.
4. Review the source data range.
5. Choose where to place the PivotTable.
6. Select **New Worksheet**.
7. Click **OK**.

Excel creates a new worksheet with a blank PivotTable and the PivotTable Field List.

The source data remains unchanged.

## 5. Understand the PivotTable Field List

The PivotTable Field List contains the column headings from your source data.

You can drag these fields into four main areas.

| Area | Purpose |
|---|---|
| Filters | Filters the entire PivotTable by selected criteria. |
| Columns | Displays categories across the top of the PivotTable. |
| Rows | Displays categories vertically down the PivotTable. |
| Values | Calculates summaries, such as sums or averages. |

The fields you select determine what the PivotTable displays.

## 6. Build a PivotTable

Suppose you want to summarize totals by office and destination.

You can build the PivotTable by dragging fields into the appropriate areas.

### Step 1: Add a Row Field

Drag **Office** into the Rows area.

Excel displays the offices down the left side of the PivotTable.

### Step 2: Add a Column Field

Drag **Destination** into the Columns area.

Excel displays destinations across the top.

### Step 3: Add a Values Field

Drag **Total** into the Values area.

Excel calculates a summary for each combination of office and destination.

The default summary function for numeric data is commonly **Sum**.

The PivotTable may contain blank cells where no records match a particular combination of categories.

These blanks can be meaningful because they may indicate that no matching transactions exist.

## 7. Change the Summary Function

Excel often defaults to summing numeric values.

However, you can change the calculation to an average, count, maximum, minimum, or another available summary function.

### Steps

1. Right-click a value in the PivotTable, or open the field's settings in the Values area.
2. Select **Value Field Settings**.
3. Choose the summary function you want, such as **Average**.
4. Click **OK**.

Excel recalculates the PivotTable using the selected function.

### Example

- **Sum of Total:** Calculates the total of the values.
- **Average of Total:** Calculates the average value.
- **Count of Total:** Counts the non-empty entries included in the calculation.

Choose the function that best answers your question.

## 8. Format PivotTable Values

If your values represent money, format them as currency.

### Steps

1. Right-click a value in the PivotTable.
2. Select **Number Format**.
3. Choose **Currency**.
4. Set the desired decimal places.
5. Click **OK**.

Using the correct number format makes the results easier to understand.

**Tip:** Use the field's number format settings where possible so that the formatting applies consistently to the PivotTable field.

## 9. Rearrange PivotTable Fields

One of the main advantages of PivotTables is how easily you can reorganize the analysis.

For example, you may decide that destinations should appear in rows rather than columns.

To change the layout:

1. Find the Destination field in the Columns area.
2. Drag it into the Rows area.
3. Review the updated PivotTable.

The office and destination categories now appear together in the row area.

Excel may also display subtotals and a grand total.

You can continue moving fields between the four areas to explore your data from different perspectives.

## 10. Refresh a PivotTable

A PivotTable does not always update automatically when its source data changes.

If the source data is edited, added to, or corrected, you may need to refresh the PivotTable.

### Steps

1. Return to the PivotTable worksheet.
2. Right-click anywhere inside the PivotTable.
3. Select **Refresh**.

Excel updates the PivotTable using the source data.

**Important:** Refreshing updates the PivotTable using its existing source range. If you add new rows outside that range, you may also need to update the source data range or use an Excel Table as the source.

## 11. Key Takeaways

- PivotTables summarize large datasets without directly changing the source data.
- Use **Insert > Recommended PivotTables** for suggested layouts.
- Use **Insert > PivotTable** to build your own.
- Drag fields into Rows, Columns, Values, and Filters.
- Numeric fields commonly default to Sum.
- Use Value Field Settings to change the summary function.
- Format monetary values using Currency.
- Rearrange fields to explore data in different ways.
- Refresh the PivotTable after relevant source data changes.
