# Data Entry Basics

## Entering Data
- To enter data in Excel, click on a cell and start typing.
- Press **Enter** to confirm the entry.

## Name Box
- The **Name Box** is located to the left of the Formula Bar.
- You can type a cell reference into the Name Box to navigate directly to that cell.

## Keyboard Shortcuts
- **Ctrl + Home (Windows):** Quickly moves to cell A1.
- **Control + Home (Mac):** Typically moves to the beginning of the worksheet.
